# 短剧故事生成 · 选项提示词库（config-options）

> 查表驱动：用户选的每个选项 → 查本表得到「生成剧本时的叙事注入」。
> 单选字段影响世界观/骨架/力量/金手指；多选字段影响叙事模式/起点/场景/节奏/基调。
> 选项可跳过（默认），跳过时按「默认」列注入。

## 三、组合规则（多选项叠加时）

1. **单选**：每项取 1 个（用户没选用默认），互斥不叠加
2. **多选**：可 0~N 项，叠加生效——流派×处境×题材×节奏×风格 共同塑造剧本
3. **力量/金手指**：每组至多 1 个，可全跳过（科幻类可不选力量体系，默认无）
4. **冲突检测**：类型=仙侠 + 力量=机甲 → 提示用户确认（世界观冲突）；不强行否决，标注「混搭需自洽」
5. **短剧适配**：所有选项最终服务于**短剧节奏**（3 分钟/集，钩子-冲突-反转-留钩）
