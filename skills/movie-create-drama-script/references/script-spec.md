# 剧情脚本数据模型与输出规范（script-spec）

> 本文档定义**剧情脚本/分镜的完整数据模型与输出模板**，供 SKILL.md 调用。
> **分镜 JSON 为主**（机器消费：审阅/机械校验/资产反推），markdown 渲染版并存（人读）。
> 对齐 ComfyUI-H3 工程的成熟机制：coverage 覆盖率 / continuity 边界锁 / assets 资产清单 / purpose 镜头目的 / 一镜一运镜。

---

## 一、设计原则

1. **对话按角色列出**：每句台词标注说话角色，供配音（TTS 分轨）与视频生成角色绑定直接使用。
2. **可演 > 可读**：动作/神态用「可拍摄的物理描述」，不是文学形容。
3. **情绪标注挂接 movie-emotional-director**：每场标注情绪节点，用 10 情绪名 + 强度。
4. **保留原文因果**：改编可以删繁就简，但不得改变剧情因果、人物关系、明确台词语义。
5. **分镜 JSON 化**：分镜输出为结构化 JSON（含 purpose/continuity/coverage/assets），供机械校验与审阅闭环消费；同时渲染 markdown 版给人读。
6. **台词逐字保留**：台词与原文逐字一致（审阅与机械校验要核对），不翻译不改写。
7. **一镜一运镜**：每镜只一种主运镜，写起点-速度-终点，禁"推+摇"同用。

## 二、分镜 JSON Schema（主格式）

```json
{
  "storyboard": {
    "episode_title": "第1集",
    "duration_seconds": 120,
    "coverage": [
      {"beat": "重生躺平", "source_text": "原文摘录", "shot_ids": [1, 2], "status": "covered"}
    ],
    "shots": [
      {
        "shot_id": 1,
        "time_range": "0:00-0:05",
        "duration": 5,
        "scene": "紫极仙宫偏殿",
        "characters": ["沈棠"],
        "props": [],
        "shot_size": "中景",
        "camera": "固定机位，从全景缓慢推近到近景后固定",
        "action": "沈棠背靠廊柱缓缓滑坐，后脑靠墙，呼吸放缓，眼皮渐沉",
        "dialogue": "（旁白）前世，我登顶修真界巅峰。",
        "speaker": "旁白(沈棠内心)",
        "sfx": "环境鸟鸣，衣料摩擦",
        "mood": "松弛",
        "hook": "定调", 
        "ref_anchors": [],
        "purpose": "让观众建立沈棠重生躺平的初始状态，为后续被吵醒做铺垫",
        "screen_direction": "",
        "continuity": {
          "start": {"position": "沈棠靠西墙角落廊柱", "posture": "坐姿微倾", "gaze": "闭眼", "props": {}},
          "end": {"position": "沈棠靠西墙角落廊柱", "posture": "滑坐更深", "gaze": "闭眼", "props": {}}
        }
      }
    ],
    "assets": {
      "characters": [{"id": "沈棠", "description": "十六七岁仙门女弟子，清秀鹅蛋脸，慵懒气质", "shots": [1, 2]}],
      "scenes": [{"id": "紫极仙宫偏殿", "description": "仙家宫殿偏殿，三面围合墙角，南窗日间光", "shots": [1]}],
      "props": [{"id": "断扫帚", "description": "竹制断成两截", "shots": [3]}]
    }
  }
}
```

### 字段说明

| 字段 | 说明 |
|------|------|
| `coverage` | 全片节拍→镜头映射，status: `covered` / `intentional_repeat` / `omitted_with_reason` / `nonvisual_context`；**禁止关键节拍无镜头落实（丢戏）** |
| `shots[].purpose` | 每镜必填：观众该注意什么 / 信息情绪变化 / 为什么切镜。禁空话（"展示场景"） |
| `shots[].continuity.start/end` | **边界锁**：位置/姿态/目线/持物/道具所有权。镜N end 必须 = 镜N+1 start；道具不得凭空出现/消失/换主 |
| `shots[].screen_direction` | 轴线：谁占画面左/右，未越轴；无多主体可省略 |
| `shots[].action` | **肢体级描述**（"慢慢抬手、用力攥地"），禁"奔跑/战斗/哭泣/愤怒"抽象动词 |
| `shots[].mood` | 情绪通过具体表情/手势/呼吸/视线呈现，非贴标签 |
| `shots[].hook` | **镜头钩子类型**：定调/信息揭示/情绪爆发/悬念/笑点/反转/压迫/转场。每镜必填——回答"这镜为什么抓人" |
| `shots[].ref_anchors` | **参考锚点**：本镜引用的资产/参考图（如 `["沈棠", "紫极仙宫偏殿"]`），供视频生成的 `<Picture N>` 引用；空 = 无参考 |
| `assets` | 角色/场景/道具 + 出场镜头号；id 用中文原名，禁翻译禁缩写 |
| `duration` | 单镜 2-5 秒；镜头数 × 平均时长 ≈ 目标时长；最后一镜结束 = 目标时长；时间连续无空洞无重叠 |
| **分镜密度** | 15s ≈ 4 镜、30s ≈ 5-6 镜、60s ≈ 7-9 镜；**每镜只讲一个信息/情绪单元**（一个知识点/一个情绪点/一个动作） |

## 三、markdown 渲染版（并存，人读）

JSON 分镜生成后，渲染一份 markdown（从 JSON 转换，不手动维护）：

```
# 剧情脚本：{小说名} 第{集}

| 镜号 | 时间 | 景别 | 场景 | 角色 | 动作/神态 | 台词 | 情绪 | 运镜 |
|------|------|------|------|------|----------|------|------|------|
| 1 | 0:00-0:05 | 中景 | 偏殿 | 沈棠 | 背靠廊柱滑坐 | 旁白：前世... | 松弛 | 缓推 |

## 资产清单
角色：沈棠（...）｜场景：紫极仙宫偏殿（...）｜道具：断扫帚（...）
```

## 四、填写规则

### 1. 分场
- 场景切换即换场；同场景时间跳变拆两场。

### 2. 台词
- 逐字保留原文，标注说话人（speaker）；台词长度与镜头时长匹配（3 秒镜头不塞长对白）。
- 内心戏转旁白，speaker 标「旁白(角色名内心)」。

### 3. 动作/神态
- 肢体级描述：起点→过程→终点；速度质感（缓慢/匀速/加速）；力度（轻柔/用力/爆发）。
- 禁文学修辞（心如刀割/怒火中烧）。

### 4. 情绪
- `movie-emotional-director: 情绪·强度`；用具体表情/手势/呼吸/视线呈现。

### 5. 运镜
- 一镜一运镜；写起点-速度-终点；单场 ≤2 个运镜。

### 6. 机械校验配合
- 分镜 JSON 产出后，跑 `validate_storyboard.cjs` 做机械校验（时长归一化/资产反推/台词核对/覆盖率核对）。

### 7. humanizer 拟人化（可选，审阅/校验通过后）
- 小说为 AI 生成时，台词用 `../shared/humanizer-zh.md` 过一遍拟人化。
- 处理 `dialogue` 字段：去 AI 味（书面排比/堆砌/金句），保留人设语气，不改语义。
- 对白逐字核对（审阅维度8）针对**入镜版**；humanizer 在语义一致基础上做最终润色。
- 非 AI 原创小说可跳过。

---

## 五、与下游的衔接

- **审阅**：movie-script-review 读 JSON 分镜，审阅-修正-复核闭环直到 PASS。
- **角色/场景卡**：assets 中的角色/场景/道具引用对应的 movie-character-card / movie-scene-card 产物。
- **配音**：movie-dialogue-table 从分镜 JSON 抽台词（speaker + dialogue + 情绪）。
- **视频**：分镜 JSON 的 camera/action/mood 是 movie-emotional-director 生成视频提示词的输入。
