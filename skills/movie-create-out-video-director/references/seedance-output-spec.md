# Seedance 输出规范（单一权威）

仅当目标模型为 Seedance 时读取。本文件定义模型专属标签、字段和模板；OUT 主 Skill 只负责公共事实、冻结对白、情绪、时间轴、动态负面、可见文字与 LOCKED 路由。

多模态提示词顺序：映射声明首段 → 一致性约束 → 六段式正文。映射声明绑定语义资产到 `<图片N>`、`<视频N>` 或 `<音频N>`；正文不得泄漏语义别名。

## 六段式完整模板

1. **视听限制**：时长、画幅、清晰度、同期声优先级、禁止无关水印/logo/乱码/外加字幕条。
2. **语言台词**：语言、冻结对白、说话人、语速音量音质、对白出现时间；剧情明确文字逐字保留。
3. **运镜手法**：景别、机位、起点、运动路径、速度变化、终点与切镜新信息。
4. **风格色调与光景**：继承冻结风格、光向、色彩关系、曝光、材质与环境反馈。
5. **角色与场景设定**：由语义映射解析出的主体、场景、道具、空间阻挡和连续性状态。
6. **时间轴详细叙事**：按时间段写动作起点/过程/终点、表演反应、声音和状态变化。

## 参考与主体

- 首段先写 `[语义资产] → <图片N>/<视频N>/<音频N>` 映射声明，随后写一致性约束，再进入六段正文。
- 主体定义格式：`将<图片1>中[2—3个稳定可见特征]定义为<主体1>`；正文只使用解析后的标签或主体名，不泄漏语义别名。
- 编辑、延长、组合任务分别写：`编辑<视频1>，保留...，替换...`；`延长<视频1>至...，保持末帧...`；`组合<视频1>与<视频2>，先...再...`。不得把编辑任务写成参考图任务，不得改变冻结对白和关键剧情。

## 压缩与质量

总字数超限时依次压缩：非台词装饰描述 → 重复环境形容 → 非关键时间段合并 → 拆分生成单元；冻结对白、剧情明确文字、主体映射和起止动作不得删节。

## Seedance QA

- 映射声明首段、一致性段和六段齐全；每个标签可解析且编号一致。
- 动作具备起点/过程/终点，镜头有新信息，声音与画面相容。
- 冻结台词逐字一致；剧情文字逐字保留；无无关水印、logo、乱码、外加字幕条。
