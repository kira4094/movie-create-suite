# 让-皮埃尔·热内《天使爱美丽》电影风格指南

## 影片美学定位句

让-皮埃尔·热内《天使爱美丽》电影美学风格——以超饱和暖金绿调为基底的魔幻现实主义视觉语法，通过极致的色彩主观化、框中框构图与精密的道具符号编码，将蒙马特的石街与日常物件升华为充满私密感的童话宇宙。

## 二、跨图证据矩阵

- **色彩系统**：三张截图共同呈现「低饱和基底 + 高饱和点缀」结构；暖金绿为全局底色（暗橄榄绿/暖琥珀），高饱和点缀（亮绿/亮黄）面积 <5%，仅作视觉引导。
- **光影系统**：室内顶光/台灯侧光为主，中高反差；室外自然光低反差。阴影均偏重、细节保留少。
- **构图系统**：三分法与中心对称并用；「框中框」（门窗、相框、竖线分割）反复出现。
- **空间与材质**：石质与金属材质反复出现，粗糙与冷硬并存；强透视纵深。
- **人物与镜头**：人物常占画面 30-45%，浅景深聚焦；服装暖灰/深色系，与环境冷色形成轻微冷暖对比。

## 三、风格特征优先级

- **全局锚点（不可妥协）**：低饱和暖金绿基底；高饱和点缀面积 <5%；中高反差 + 暗部压重；框中框构图。
- **条件性变体**：日间室外低反差自然光；夜间室内高反差暖琥珀主光。
- **单一测试变量**：点缀色具体色相（亮绿 vs 亮黄）——跨图证据未完全一致，仅作测试参数。

## 四、全局视觉基线

- 色彩：主色暗橄榄绿 #5C6B30 / 辅色青灰 #8A8F85 / 点缀亮绿 #7ABF2E（面积 40/35/5）
- 光影：顶光或侧前方主光，中高反差，暗部压重，阴影有叙事作用
- 构图：框中框 + 三分法，强透视纵深，浅景深聚焦人物
- 材质：石质/金属/粗糙表面，避免光滑塑料感

## 五、条件性变体

- 日间室外：低反差、暖褐主导、中心对称
- 夜间室内：高反差、暖琥珀主光、浅景深
