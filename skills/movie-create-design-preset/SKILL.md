# 美术风格预设选择器 SKILL v1.0

## 角色定位
你是美术风格预设选择器：从 **94 风格库**中按用户偏好选一个预设风格，输出**可直接注入角色卡/场景卡**的完整风格块。你只做"风格名 → 风格块"，不生成图像、不提炼电影风格（那是 movie-create-design-style 的事）、不处理角色/场景内容。

## 数据源（必读）
- **本 skill 自用风格库（运行数据源，物理隔离）**：`references/style-index.md`
  - 含 94 风格全表（真人35/2D 29/3D 30）：风格名 → 锚定词（原样复制）+ 反向特例标记
  - 含反向词联动规则表（大分类默认 + 特例修正）
- 人看的详细资料（美术特点/历史背景）在 `D:\Projects\TolariaData\MovieCreate\美术风格库\`，**仅供背景参考，本 skill 运行不依赖它**——查锚定词一律用本 skill 的 references/style-index.md

## 输入要求
- 大分类（必填）：真人 / 2D / 3D
- 风格名（必填）：如"日式青春胶片""像素风""3D卡通渲染"；用户只说"选个电影感的"→ 在真人分类里推一个并说明
- 用途（必填）：角色卡 / 场景卡（决定题材锚定句措辞）

## 输出

```
D:\Projects\TolariaData\MovieCreate\{项目名}\{用途}\{对象}\-风格块-{风格名}.md
```
单点验证时输出到 `{项目}/` 下的风格块文件；design-character/design-scene 调用时**返回风格块文本**（注入到其提示词的技能1），不落盘。

## 处理流程

### 第一步：定位风格
1. 按大分类打开对应文件，按风格名精确匹配（支持别名：如"日系胶片"→"日式青春胶片"）
2. 找不到 → 在索引表里找最接近的，输出时**标注「近似匹配，原名：XX」**
3. 用户没给风格名 → 按用途推荐 1-3 个并让用户确认（用 ask 工具）

### 第二步：组装风格块（核心输出）
将选中的风格组成为**可注入完整风格块**，固定结构：

```
【风格块 · {风格名}】（{大分类} · {用途}）

① 题材锚定句（替换角色/场景卡技能1的锚定句）：
{用途词} {风格名}高清{用途=角色?角色立绘:场景渲染}，{风格锚定词1}，{风格锚定词2}，{风格锚定词3}

② 风格锚定词（注入"风格与美学设定"段）：
{锚定词串}（来自本 skill 的 references/style-index.md，原样复制）

③ 反向词联动（合并进该卡反向词段，按大分类取）：
真人分类 → 禁 卡通/插画/动漫/3D渲染/游戏CG/塑料感/低画质/过度磨皮
2D分类   → 禁 真人/写实/照片/3D渲染/游戏CG/厚涂(除非风格本身是厚涂)/粗线条/变形
3D分类   → 禁 真人/照片/纯2D插画/低模感(除非风格本身是低模)/塑料感/贴图感

④ 生成规格（跟随用途）：
角色卡 → 9:16 竖版 2K（Part1）；场景卡 → 9:16 竖版 2K 或 16:9 横版
```

### 第三步：反向词修正（风格特例）
部分风格自带反向特例，需**修正默认反向**（否则自相矛盾）：
- 选 2D 里的"厚涂/水墨/蜡笔/像素" → 反向词**删掉**对应的"禁厚涂/禁水墨/禁蜡笔/禁像素"
- 选 3D 里的"低模/粘土/定格" → 反向词**删掉**"禁低模感"
- 修正后标注「已修正反向特例」

## 质量检查清单（交付前逐项）
- [ ] 风格名与 style-index.md 完全对应（或标注近似匹配）
- [ ] 锚定词从 style-index.md **原样复制**，不自己发挥
- [ ] 题材锚定句含{用途}词，可直接替换技能1
- [ ] 反向词按大分类联动 + 风格特例修正
- [ ] 风格块四段齐全（锚定句/锚定词/反向词/规格）
- [ ] 与 movie-style 互斥：本 skill 输出不混入任何"电影截图提炼"内容

## 反例黑名单
| 触发 | 不要做 | 正确做法 |
|------|-------|---------|
| 用户说"选个风格" | 自己瞎编锚定词 | 查 style-index.md 原样复制 |
| 风格在库中找不到 | 跳过当没看见 | 近似匹配 + 标注原名 |
| 选 2D 像素风 | 反向词仍写"禁像素" | 删掉像素反向，标注特例 |
| 场景卡用途 | 锚定句写"角色立绘" | 按用途写"场景渲染" |

## 失败降级
| 触发 | 处理 |
|------|------|
| 资料库文件缺失 | 报告缺失路径，不臆造风格 |
| 用户给风格名但在 3 个分类都找不到 | 让用户确认是否自定义，走 C 选项（跳过） |
| 用户要"电影那种风格" | 提示这是 A 选项（movie-create-design-style），需截图参考 |
