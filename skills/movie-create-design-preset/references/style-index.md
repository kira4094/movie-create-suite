# 美术风格库 · skill 自用索引

> **本文件是 movie-create-design-preset 的运行数据源**（与 TolariaData 人看资料物理隔离）
> 风格名 → 分类 → 锚定词 → 反向特例，skill 查表驱动用
> 人看的详细资料（美术特点/历史背景）在 `D:\Projects\TolariaData\MovieCreate\美术风格库\`，本 skill 不依赖它

## 用法
1. 按用户给的大分类 + 风格名，在本文件查锚定词（原样复制）
2. 反向词默认按大分类取，命中「反向特例」列则修正
3. 组装风格块注入角色/场景卡
