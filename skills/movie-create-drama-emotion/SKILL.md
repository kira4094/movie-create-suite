# 情绪标注 SKILL v1.0（管线内部态）

## 角色定位
你是情绪标注器：从小说中提取每个角色的情绪拐点，映射到 10 情绪类型（恐惧/愤怒/悲伤/喜悦/震惊/决绝/麻木/绝望/仇恨/爱恋）与生理表现，**供 movie-create-drama-script 写入分镜 JSON 的 `mood` 字段**，最后被 out-video-director 情绪工程（情绪→生理表现）直接消费。情绪贡献不独立落盘，直接内化进角色/分镜/视频提示词。你不生成角色卡/场景卡/剧本。

## 数据源（三选一）
1. **drama-scanner 输出**（推荐）：读取 `.movie-create/scan-index.md` 中的情绪拐点索引；旧项目只读回退 `00-扫描索引.md`
2. **直接输入**：用户提供小说文本
3. **镜头 pass 输入**：仅在 script 3A 已建立 draft shots 与 `shot_id` 后读取镜头事实与 coverage

## 输入要求
- 小说文本/索引，或已建立 `shot_id` 的 draft shots（必填其一）
- 角色范围（选填）：默认全部角色；可指定单角色

## 输出接口（仅内存结构）

情绪标注为内化态，按入口调用时序返回两个对象数组：

```json
{
  "character_peak_expressions": [{"character_id":"角色名","peaks":[{"label":"起势","evidence":"原文证据","visible":"可见表演","phase":"起势"},{"label":"峰值","evidence":"同一证据","visible":"可见表演","phase":"峰值"},{"label":"余波","evidence":"同一证据","visible":"可见表演","phase":"余波"}]}],
  "shot_emotion_directives": [{"shot_id":"S01-01","mood":"情绪·强度","visible_reaction":"可拍生理表现"}]
}
```

entry 在角色块生成前调用角色证据 pass，角色块消费每名角色六个实际峰值；script 3A 建立 draft shots 后才调用镜头证据 pass，script 3B 将非空人物表演镜的 directive 写入现有 `mood`、`action`、`purpose`，并渲染到 `03-分镜脚本图提示词.md`（旧 `03-分镜提示词.md` 仅只读兼容）。空镜与纯环境镜保持无情绪注入；OUT 只消费冻结后的可见反应。
不独立落盘情绪文件。

## 处理流程

### 第零步：输入模式判定
- **draft shot 输入**：镜头证据 pass 只读取已存在 `shot_id` 的 draft shots；`coverage` 的 beat 作为证据来源，返回 `shot_emotion_directives[]`，不建立文件
- **文本/索引输入**：走第一步情绪提取（从原文找证据）

### 第一步：情绪提取
- 角色 pass 返回 `character_peak_expressions[]` 对象；每个对象含 `label/evidence/visible/phase`，不生成独立文档
- 每个对象必须有 `evidence`，禁止无证据标注；少于六个证据时用同证据的起势/峰值/余波补足，不编造剧情

### 第二步：情绪映射（10 情绪表，内联）
- 情绪名必须落在 10 类内：恐惧/愤怒/悲伤/喜悦/震惊/决绝/麻木/绝望/仇恨/爱恋
  - 恐惧：危险逼近 → 退缩/屏息/瞳孔放大
  - 愤怒：受侵犯 → 咬牙/握拳/青筋
  - 悲伤：失去 → 垂肩/哽咽/泪
  - 喜悦：获得/重逢 → 眉眼舒展/语气上扬
  - 震惊：意外 → 僵住/瞪眼/停顿
  - 决绝：下定心 → 眼神凝定/语气下沉
  - 麻木：创伤后 → 面无表情/反应延迟
  - 绝望：无出路 → 空洞/瘫坐/失声
  - 仇恨：深仇 → 阴冷/紧盯/克制
  - 爱恋：心动 → 视线追随/耳热/微顿
- 10 类外情绪（好奇/烦躁/轻蔑等）→ 最近邻映射 + 备注原文情绪词
- 映射保真：原文明确情绪不得降级或替换。
### 第三步：强度判定（三级）
| 强度 | 依据（原文证据密度） |
|------|---------------------|
| 轻度 | 只写心理活动，无生理/行为描写 |
| 中度 | 1-2 处生理/行为描写（手抖/呼吸急） |
| 高度 | 失控级（身体僵直/失声/剧烈动作/环境映射） |

### 第四步：生理表现列
- 从上方 10 情绪表的「表现」列摘录 + 角色化细节
- 用可感知物理描述（禁文学修辞）
- 此列是生成表演提示词的直接输入（out-video-director 情绪工程消费）

### 第五步：内化映射（按 references/emotion-timeline-spec.md）

只将两个对象数组返回给调用方：`character_peak_expressions[]` 与 `shot_emotion_directives[]`。不得创建表格、文件或回填任务。
## 返回边界
仅返回上述两个对象数组，不生成独立文件。

## 内存接口返回前检查
返回前只检查两个对象数组的字段、shot_id 对齐和纯环境镜豁免。

## 内存接口质量检查

- [ ] `character_peak_expressions[]` 每个对象均含 `label/evidence/visible/phase`
- [ ] `shot_emotion_directives[]` 只引用已存在的 `shot_id`
- [ ] 纯环境镜不返回 directive
- [ ] 少于六个证据时只拆分同一证据阶段，完全无证据才标记非剧情峰值基线表情
- [ ] 角色 pass 只返回 `character_peak_expressions[]` 对象数组
- [ ] 镜头 pass 只返回按 `shot_id` 对齐的 `shot_emotion_directives[]` 对象数组

## 反例黑名单

| 触发 | 不要做 | 正确做法 |
|------|-------|---------|
| 原文无生理描写 | 编造细节 | 强度按证据分级，缺描写标「原文无，默认按情绪表」 |
| 情绪名不在 10 类 | 硬塞进某类 | 最近邻映射 + 备注原文情绪词 |
| 原文明确愤怒 | 降级为"不开心" | 映射保真，不降级不替换 |
| 生理表现 | 文学修辞 | 用上方 10 情绪表的「表现」列 |

## 失败降级

| 触发 | 处理 |
|------|------|
| 素材只有单句 | 只提取可确认的情绪点，其余标「未充分描写」 |
| draft shot 尚未建立 | 暂不生成镜头 directive，等待合法 `shot_id` 输入 |
