# 情绪证据内存接口规范（emotion-timeline-spec）

> 本文档只定义两个内存 pass：角色证据 pass 不需要 shot_id；镜头证据 pass 只能在 script 已建立 draft `shot_id` 后调用。不创建 Markdown 产物或 sidecar。
> 目标：从小说中提取每个角色的情绪拐点，标注章节/事件/情绪名/强度/原文证据，并映射到 10 情绪类型（恐惧/愤怒/悲伤/喜悦/震惊/决绝/麻木/绝望/仇恨/爱恋），使后续视频生成的表演提示词可直接引用。

---

## 一、设计原则

1. **不重复造情绪表**：情绪→生理表现映射表在 SKILL.md 内联（10 情绪 × 表现）。本规范只做「提取 + 标注 + 映射」，不复制该表。
2. **每个节点必须有原文证据**：情绪标注不是主观发挥，必须有原文段落支撑（引用原文关键句）。
3. **强度分级**：轻度 / 中度 / 高度，由原文描写的生理/行为细节密度决定。
4. **全角色覆盖**：主角、主要配角、反派均返回实际峰值；NPC 只返回必要峰值，不创建独立时间轴。
5. **与 draft 对齐**：镜头证据 pass 只引用已存在的 `shot_id`，不反向回填或建立独立文件。

---

## 二、内存结构

```json
{
  "character_peak_expressions": [{"character_id":"角色名","peaks":[{"label":"起势","evidence":"原文证据","visible":"可见表演"},{"label":"峰值","evidence":"同一证据","visible":"可见表演"},{"label":"余波","evidence":"同一证据","visible":"可见表演"}]}],
  "shot_emotion_directives": [{"shot_id":"已存在的draft shot_id","mood":"情绪·强度","visible_reaction":"可见表演"}]
}
```

---

## 三、填写规则

### 1. 情绪提取
- 每个角色每章提取 1-3 个情绪拐点：情绪**开始变化**的点、**峰值**、**转化/回落**点。
- 情绪名必须落在 10 类内；10 类覆盖不了的（如「好奇」）映射到最近邻（如 震惊·轻度）并在备注标注原文情绪词。
- 禁止无原文支撑的情绪标注。

### 2. 强度判定
| 强度 | 判定依据（原文证据密度） |
|------|------------------------|
| 轻度 | 原文只写心理活动，无明显生理/行为描写 |
| 中度 | 原文有 1-2 处生理/行为描写（手抖、呼吸急等） |
| 高度 | 原文有失控级描写（身体僵直、失声、肢体动作剧烈、环境映射） |

### 3. 生理表现列
- 从 SKILL.md 内联 10 情绪表的对应行摘录 + 角色化细节。
- 用可感知物理描述，禁止文学修辞。
- 此列是 out-video-director 生成视频表演提示词的直接输入。

### 4. 两阶段 pass
- 角色 pass 在角色块前运行，不需要 `shot_id`。
- 少于六个证据峰值时，不编造新剧情；把同一证据拆为起势/峰值/余波等不同可见表演帧，并标注同一证据来源。
- 完全没有情绪证据时，才使用角色基线表演测试表情，并明确标注“非剧情峰值”。
- 镜头 pass 必须等待 script 建立 draft shots 与 `shot_id` 后运行；空镜/纯环境镜不返回情绪 directive。

### 5. 对象数组约束
- 只返回 `character_peak_expressions[]` 与 `shot_emotion_directives[]`；不输出任何独立文档或跨文件回填内容。

---

## 四、10 情绪映射规范

| 小说原文情绪 | 映射 | 备注 |
|-------------|------|------|
| 害怕/紧张/惊慌 | 恐惧 | 紧张→恐惧·轻度；惊慌→恐惧·中度 |
| 生气/恼火/暴怒 | 愤怒 | 恼火→愤怒·轻度；暴怒→愤怒·高度 |
| 难过/沮丧/哀痛 | 悲伤 | 按程度分级 |
| 开心/兴奋/狂喜 | 喜悦 | 按程度分级 |
| 惊讶/愕然/震撼 | 震惊 | 愕然→震惊·轻度；震撼→震惊·高度 |
| 坚定/狠下心 | 决绝 | — |
| 无感/心死 | 麻木 | — |
| 万念俱灰 | 绝望 | — |
| 怨恨/刻骨仇恨 | 仇恨 | — |
| 心动/眷恋/深情 | 爱恋 | — |
| 好奇/疑惑/怀疑 | 震惊·轻度 | 需备注原文情绪词 |
| 轻蔑/不屑 | 决绝·轻度 | 需备注原文情绪词 |
| 其他 10 类外情绪 | 最近邻映射 | 必须备注原文情绪词 |

> 规则：映射必须保真——原文明确表达的情绪不得降级或替换；10 类外的用最近邻 + 备注，不硬套。
