# 情绪时间轴数据模型与输出规范（emotion-timeline-spec）

> 本文档定义**情绪时间轴的完整数据模型与输出模板**，供 SKILL.md 的 Phase 4 使用。
> 目标：从小说中提取每个角色的情绪拐点，标注章节/事件/情绪名/强度/原文证据，并映射到 10 情绪类型（恐惧/愤怒/悲伤/喜悦/震惊/决绝/麻木/绝望/仇恨/爱恋），使后续视频生成的表演提示词可直接引用。

---

## 一、设计原则

1. **不重复造情绪表**：情绪→生理表现映射表在 SKILL.md 内联（10 情绪 × 表现）。本规范只做「提取 + 标注 + 映射」，不复制该表。
2. **每个节点必须有原文证据**：情绪标注不是主观发挥，必须有原文段落支撑（引用原文关键句）。
3. **强度分级**：轻度 / 中度 / 高度，由原文描写的生理/行为细节密度决定。
4. **全角色覆盖**：主角、主要配角、反派均需独立时间轴；NPC 只记情绪峰值，不建全轴。
5. **与剧情脚本互引**：情绪时间轴与剧情脚本（script-spec）互相引用场次编号，保持同一事件在两个文档中可对查。

---

## 二、情绪时间轴结构（输出模板）

```

| 情绪名 | 典型生理表现（节选） | 本剧适用角色 |
|--------|--------------------|-------------|
| 恐惧 | 瞳孔扩大，胸口快速起伏，手指轻颤，身体后缩 | {角色名} |
| ... | | |

## 角色 1：{角色名}

| 节点 | 章节 | 事件 | 情绪 | 强度 | 原文证据 | 生理表现（可表演） | 脚本互引 |
|------|------|------|------|------|---------|------------------|---------|
| E01 | 第1章 | {事件描述} | {10类情绪名} | {轻度/中度/高度} | "{原文关键句}" | {瞳孔骤然收缩，嘴巴微张未合...} | S01 |
| E02 | 第3章 | {事件描述} | {10类情绪名} | {中度} | "{原文关键句}" | {...} | S03 |
| ... | | | | | | | |

## 角色 2：{角色名}
（结构同上）

## NPC 情绪峰值表（可选）
| 角色 | 章节 | 事件 | 情绪 | 原文证据 |
|------|------|------|------|---------|
| {NPC名} | 第1章 | {事件} | {情绪} | "{原文}" |
```

## 三、填写规则

### 1. 情绪提取
- 每个角色每章提取 1-3 个情绪拐点：情绪**开始变化**的点、**峰值**、**转化/回落**点。
- 情绪名必须落在 10 类内；10 类覆盖不了的（如「好奇」）映射到最近邻（如 震惊·轻度）并在备注标注原文情绪词。
- 禁止无原文支撑的情绪标注。

### 2. 强度判定
| 强度 | 判定依据（原文证据密度） |
|------|------------------------|
| 轻度 | 原文只写心理活动，无明显生理/行为描写 |
| 中度 | 原文有 1-2 处生理/行为描写（手抖、呼吸急等） |
| 高度 | 原文有失控级描写（身体僵直、失声、肢体动作剧烈、环境映射） |

### 3. 生理表现列
- 从 SKILL.md 内联 10 情绪表的对应行摘录 + 角色化细节。
- 用可感知物理描述，禁止文学修辞。
- 此列是 out-video-director 生成视频表演提示词的直接输入。

### 4. 脚本互引
- 节点对应剧情脚本的场次（S01/S02...），双向可查。
- 情绪时间轴先行，剧本撰写时回填场次号；或剧本先行，时间轴回填——由 SKILL.md 流程顺序决定（Phase 4 并行产出，最终互引一致）。

### 5. 情绪曲线汇总（可选输出）
- 每角色给一条曲线：`平静 → 震惊 → 愤怒 → 决绝 → 释然`，供导演把握整剧情绪节拍。
- 遵循 10 情绪表的正向/负向链模板。

---

## 四、10 情绪映射规范

| 小说原文情绪 | 映射 | 备注 |
|-------------|------|------|
| 害怕/紧张/惊慌 | 恐惧 | 紧张→恐惧·轻度；惊慌→恐惧·中度 |
| 生气/恼火/暴怒 | 愤怒 | 恼火→愤怒·轻度；暴怒→愤怒·高度 |
| 难过/沮丧/哀痛 | 悲伤 | 按程度分级 |
| 开心/兴奋/狂喜 | 喜悦 | 按程度分级 |
| 惊讶/愕然/震撼 | 震惊 | 愕然→震惊·轻度；震撼→震惊·高度 |
| 坚定/狠下心 | 决绝 | — |
| 无感/心死 | 麻木 | — |
| 万念俱灰 | 绝望 | — |
| 怨恨/刻骨仇恨 | 仇恨 | — |
| 心动/眷恋/深情 | 爱恋 | — |
| 好奇/疑惑/怀疑 | 震惊·轻度 | 需备注原文情绪词 |
| 轻蔑/不屑 | 决绝·轻度 | 需备注原文情绪词 |
| 其他 10 类外情绪 | 最近邻映射 | 必须备注原文情绪词 |

> 规则：映射必须保真——原文明确表达的情绪不得降级或替换；10 类外的用最近邻 + 备注，不硬套。
