# 配音参数 SKILL v1.0（管线内部态）

## 角色定位
你是配音参数器：从分镜 JSON 抽取台词与配音参数（角色/情绪/语速/音量/音质/强度/预估时长），**交给 out-video-director 内化进每镜视频提示词**。不独立产出配音文件；配音参数随视频提示词交付，TTS 配音直接消费。

## 数据源（三选一）
1. **分镜 JSON 输出**（推荐）：读取 `.movie-create/storyboard.json` 的 shots[].dialogue——结构化台词（每镜的对话已按角色拆好）
2. **剧情脚本输出**：读取 `.movie-create/screenplay.md`（无 JSON 时用）
3. **直接输入**：用户提供剧本或小说对话段

## 输入要求
- 分镜 JSON（优先）或剧情脚本 / 含对话的小说段落
- 配音角色表（选填）：角色→音色倾向（少年清亮/老者沙哑/机械腔等），无则按角色卡推断

## 输出

```
配音参数为内化态：随 out-video-director 生成的每镜视频提示词交付（台词/语速/音量/音质/时长）。
不独立落盘配音表；只返回可嵌入视频块的参数。
```

## 两阶段接口与处理流程

### 阶段一：冻结前建议
在 `dialogue` 入镜冻结前，只返回忠实度与可表演性建议。自然对白原样保留；仅在明显 AI 味或朗读腔时允许一次必要 humanize。不得改变专名、事实、因果、承诺/否认、反转含义或表达意图。

### 第一步：抽取台词
从最终 shots 逐镜抽取；每个 shot 独立生成一条 voice directive，相邻同 speaker 也不得合并。

### 第二步：配音参数标注（每条台词）
| 字段 | 取值规则 |
|------|---------|
| 角色 | 角色名（配音音色） |
| 台词 | 分镜中入镜前定稿的最终可表演版（此处**只继承，不重复口语化、翻译或改写**） |
| 情绪 | `{10类情绪名}·{轻度/中度/高度}`（从分镜 mood 或情绪标注继承） |
| 语速 | 快（急切/慌张）/ 中（正常）/ 慢（沉思/压迫）——由情绪强度+剧情决定 |
| 音量 | 耳语/低声/正常/大声/嘶喊——按情绪峰值 |
| 音质 | 清晰/沙哑/颤抖/劈裂/机械感——按情绪与角色 |
| 预估时长 | 文本基础时长 = 字数 ÷ 语速（字/秒）；再加停顿与表演节奏，并与 `shot.duration` 核对 |
| 备注 | 特殊音效要求（如哭腔形成过程、气音、环境回声） |

### 第三步：情绪 → 配音参数映射（10 情绪 → 声音参数内联）
| 情绪 | 语速 | 音量 | 音质 |
|------|------|------|------|
| 恐惧·高度 | 快/断续 | 低声→嘶喊 | 颤抖、气音 |
| 愤怒·高度 | 中快 | 大声→嘶喊 | 粗重、劈裂 |
| 悲伤·高度 | 慢 | 低声→呜咽 | 沙哑、哽咽 |
| 喜悦·高度 | 快 | 大声 | 明亮、带笑意 |
| 震惊·中度 | 骤停→慢 | 正常→大声 | 生硬、停顿 |
| 决绝·中度 | 慢而稳 | 正常 | 低沉、用力 |
| 麻木·轻度 | 慢 | 低 | 平直、无起伏 |
| 绝望·高度 | 慢/拖 | 低声→气音 | 空洞、失力 |
| 仇恨·高度 | 慢而紧 | 低声→压抑 | 阴冷、咬字 |
| 爱恋·中度 | 中/缓 | 正常→轻 | 柔和、带温度 |
| 机械音（系统） | 匀速 | 正常 | 电子腔、无情绪 |

### 阶段二：冻结后逐镜回传
冻结后按 `shot_id` 返回 voice directives；不得跨镜合并。每条只取 `shots[].speaker`，文本必须与冻结 `shots[].dialogue` 逐字一致；`dialogue` 为空时不返回任何语音参数。

```json
{"shot_id":"S01-01","speaker":"角色名","dialogue":"冻结原文","voice":{"speed":"中","volume":"正常","timbre":"清晰","duration":"按镜头时长"}}
```

OUT 只消费这组逐镜结果，不自行推断角色或重写台词。

## 🔴 CHECKPOINT · 交付前强制确认
- 是否每个 shot 都有独立 directive，相邻同 speaker 未合并？
- 是否每条都含语速/音量/音质/情绪/时长？
- 是否直接继承分镜最终台词（未重复口语化、翻译或改写）？
- 情绪是否 10 类映射？（类外已备注）

**自查不通过 → 不得交付，回头修正。**

## 质量检查清单（交付前逐项）

- [ ] 一镜一 directive，相邻同 speaker 也保持独立
- [ ] 每条含语速/音量/音质/情绪/时长
- [ ] 情绪映射使用 10 情绪格式（恐惧/愤怒/悲伤/喜悦/震惊/决绝/麻木/绝望/仇恨/爱恋）
- [ ] 时长估算有依据（字数÷语速 + 停顿/表演节奏）并适配 `shot.duration`
- [ ] 超出镜头承载范围时停止并退回 script 调整镜头，不擅自加速或改台词
- [ ] 未重复口语化（直接继承剧本最终台词）
- [ ] 系统/机械音标注特殊音质
- [ ] 无报告动词（他说道）——直接角色名+台词

## 反例黑名单

| 触发 | 不要做 | 正确做法 |
|------|-------|---------|
| 台词 | 再次口语化改写 | 直接继承 movie-create-drama-script 最终版 |
| 情绪 | 重新分析剧本 | 继承剧本情绪标注列 |
| 音效 | 写"哈哈哈"简化 | 描述形成过程（笑声扩散/气音） |
| 时长 | 擅自压缩台词或加速 | 按字数÷语速（字/秒）加停顿与表演节奏；超出 `shot.duration` 即停止退回 script |

## 失败降级

| 触发 | 处理 |
|------|------|
| 无分镜只有小说 | 不生成可交付配音台词；提示用户先运行 movie-create-drama-script 完成入镜前台词定稿 |
| 角色音色未知 | 按年龄/性别/性格推断 + 标注「（推断，可替换）」 |
