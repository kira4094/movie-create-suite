# 角色设计语汇库（design-character 私有积累）

> **用途**：生成角色卡时，按题材+人设查本库取**设计语汇**（服装/材质/发型/配色/妆容+配饰），避免临场编造、保证设计水准。
> **来源**：赛博朋克 2077 公共常识 + 已验证样本 + 用户提供的 16 份角色设计方案（公众号·冬冬的智能助手，2026-08-14 提炼）。标「✅已验证」= 用户认可；标「📐样本提炼」= 来自高质量方案样本。
> **与样本库关系**：样本库 = 已验证的具体角色；本库 = 题材/人设级设计元素字典。

---

## 核心规律（所有题材通用）

1. **人设词驱动**：先定「人设词」（甜酷辣妹/盐系少年/清冷御姐…）→ 再按人设配元素。人设词 = 气质的锚。
2. **矛盾气质**：气质是**矛盾组合**（又甜又酷/又甜又拽/清冷温柔+疏离），不是单维度。两个对立词叠加 = 高级感。
3. **妆面体系名**：韩式（蜜桃粉珊瑚/水光肌/卧蚕）/ 美式白开水妆 / 伪素颜 / 猫系——用**完整体系名**比零散描述有效。
4. **材质对比度**："不同材质反射率差异明显"——服装要**材质反差**（针织柔软+牛仔挺括+真皮硬朗），质感来自反差。
5. **配色克制**：主色 ≤3 个，低饱和显高级（白+灰+黑/米白+卡其/黑+荧光绿点缀）。
6. **输出规格**：四宫格（面部特写+正/侧/背）或 三视图+大头特写；8K、棚拍柔光、中性灰/纯白背景。
7. **摄影参数**：85mm f/2.0 / 105mm f/1.8 人像镜头、电影级光影、真实皮肤纹理（禁塑料磨皮）。

## 体型比例/身材选择项（跨题材通用，2026-08-14 用户建议）

> 生成角色技能2 体型时查本节。**比例决定腿长视觉，身材类型决定轮廓**——两者组合填技能2。
> 已标注 ✅ = 用户验证有效。

### 比例维度（上下身比例）
| 比例 | 效果 | 适用 | 提示词写法 |
|---|---|---|---|
| 4:6 | 腿长视觉拉长，模特感 | 高挑/性感/御姐 | 「上下身比例 4:6（上半身4、下半身6，腿部视觉拉长）」✅小优 |
| 3:7 | 超模比例，极致腿长 | 模特/女神 | 「上下身比例 3:7（超模比例）」 |
| 4.5:5.5 | 微拉长，自然 | 通用 | 「上下身比例 4.5:5.5」 |
| 5:5 | 均衡普通 | 日常/邻家 | 「上下身比例 5:5」 |

> **穿高跟注意**：5:5 穿高跟易显"被撑起"不自然；4:6/3:7 让腿更长，高跟融入比例（✅小优验证）。

### 身材类型
| 类型 | 描述 | 适用人设 | 提示词写法 |
|---|---|---|---|
| 性感S | 胸大腰细臀翘，S曲线明显 | 致命尤物/御姐/蛇蝎美人 | 「胸大腰细臀翘（S曲线明显）」✅小优 |
| 纤细修长 | 高挑清瘦，长腿，骨感 | 清冷/仙气/文艺 | 「身形纤细修长，长腿」 |
| 曲线丰满 | 丰腴圆润，比例协调 | 熟女/风韵/市井老板娘 | 「身形丰腴圆润，比例协调」 |
| 匀称健美 | 紧实有肌肉感，线条流畅 | 运动/女战士/女将 | 「身形匀称健美，肌肉线条流畅」 |
| 娇小软萌 | 小巧可爱，显小显嫩 | 少女/甜妹/萝莉 | 「身形娇小，比例显小显嫩」 |
| 魁梧壮硕 | 宽肩厚背，肌肉猛男 | 猛男/硬汉/将军 | 「身形魁梧壮硕，宽肩厚背，肌肉轮廓明显」✅老陈 |
| 高瘦清俊 | 瘦高挺拔，衣架子 | 少年/公子/剑客 | 「身形高瘦挺拔，清俊」 |

### 组合规则
1. 比例 + 身材类型 组合填技能2（如小优：「4:6 比例 + 性感S」）
2. 比例优先于身高（写比例比写"175cm"更管用，模型更易执行）
3. 负面词加「身材比例失调（55开/上下身等长）」防模型退回等长

1. 生成角色前：查本库 → 按**题材 + 人设词**取语汇（如"现代都市·甜酷辣妹"→ 白抹胸+包臀裙+裸棕唇）

3. 语汇填入 Part 1 技能4/5/6/7 对应槽位
4. 用户反馈 → 更新语汇（标注 ✅已验证）
