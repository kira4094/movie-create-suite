# 角色卡数据模型与输出规范（character-card-spec）

> 本文档定义**角色卡的完整数据模型与输出模板**，供 SKILL.md 调用。
> 目标：产出一份可直接用于「文生图」生成角色资产图的角色卡，保证角色在整部小说中**前后视觉一致**。
> **提示词统一采用「角色+技能+限制」分条结构**（可编辑性强，文生图/图生图通用）。

---

## 一、设计原则

1. **一致性锚点 = 素体内衣层**：先锁定「无外袍」的素体（体型、发型、面部特征、肤色），再在其上叠加服装线。所有服装变体共享同一素体，防止换装即换脸。
2. **服装线按剧情时间排序**：全本扫描阶段收集角色每一次服装/外观变化节点，服装卡逐套列出，覆盖整部小说。
3. **表情库服务于情绪表演**：从剧情情绪峰值中提取表情，映射到 movie-create-drama-emotion 的 10 情绪表，供视频生成的生理表现引用。
4. **颜色一律 HEX #RRGGBB 标注「（文字推断）」**：小说无截图证据，所有色值为文本推断，附 1-2 个备选。
5. **提示词为可生成工程指令**：禁止文学化修辞，表情描述写「可感知的肌肉/生理变化」。
6. **美术风格与反向词互斥（铁律）**：正向风格词决定反向词库——正向写实真人则反向禁「卡通/插画」；正向二次元则反向禁「写实/真人/3D渲染」。**禁止自相矛盾**（正向写实却反向也禁写实）。
7. **题材锚定句**：每套提示词必带 `国产{题材词}真人高清角色定妆棚拍`，题材词与风格六维来自 `shared/style-dna.md`。
8. **素体=静态锚点，情绪=表情库（分离铁律）**：素体层只写**静态结构**（脸型/五官/体型/发型/标志性特征）与**气质底色**（干练/清冷/慵懒/痞气等性格体现）；**禁止任何当下情绪/神情描述**（眼皮半垂、神情倦怠、嘴角下垂、蹙眉等）。素体提示词固定含「中性表情，目视镜头，无特定情绪」——所有喜怒哀乐由表情库承载。
   - **气质底色 vs 情绪边界**：气质底色 = 长期稳定性格（警觉沉静/清冷/慵懒），可写；情绪/神情 = 当下状态（眼神藏着心事/眼皮半垂/蹙眉），禁写。「眼神藏着心事」是神态 → 删，只留「警觉沉静」。
   - **妆容按题材个性化**：素体「淡妆」默认仅用于日常题材；赛博朋克/玄幻等题材妆容应体现世界观（赛博=上挑眼线/冷色唇/亮片/发光纹身，玄幻=花钿/额饰），不套「淡妆」默认。（2026-08-14 用户指出）
9. **提示词分条结构（统一格式）**：所有提示词用「角色+技能1..N+限制+生成规格」分条，每条独立可编辑，文生图/图生图通用。

## 八、角色资产四部分管线（Part 1-4，固化版）

> 实测验证通过的资产生成链路。Part 1 是角色专属锚，Part 2/3/4 是通用模板（只换参考图 + 占位槽）。

### Part 1：全身定妆照（角色专属 · 文生图）
- 作用：锁定角色全部信息（身份/体型/脸/发型/服装/气质）——后续一切的参考锚
- 提示词：分条技能结构（见「二」模板），技能2 含体型身材描述（后续 Part 2 身材一致性靠此 + 参考图双锚定）
- 生成规格：9:16 竖版，2K

### Part 2：多视图（通用模板 · 图生图，参考图 = Part 1）
- 作用：头部三视图（上 1/3）+ 脖子以下三视图（下 2/3）
- 技能要点：
  - 技能1 任务类型：以上方参考图为唯一基准
  - **下区裁切铁律**：从颈部横截面向下裁切，顶部边缘即颈部切口；只显示锁骨/肩/躯干/四肢到鞋；严禁头部/面部/下巴/头发
  - 一致性：六幅视图比例/姿态/服装/配饰完全一致
  - 反向词加：下区出现头部/面部/下巴/头发
- 使用提示：用户在实际使用中会在提示词前强调引用全身图（补身材一致性）
- 生成规格：3:4 竖版，2K
- 失败降级：① 下区改全身三视图（放弃脖子以下，最稳）② 分两张生成后拼版 ③ 局部重绘

### Part 3：情绪卡（通用模板 · 图生图，参考图 = Part 1 正面）
- 作用：10 情绪表情卡（2行×5列），情绪= movie-create-drama-emotion 全 10 情绪
- 情绪排布（固定顺序，供位置引用）：上排 恐惧/愤怒/悲伤/喜悦/震惊，下排 决绝/麻木/绝望/仇恨/爱恋
- 技能要点：
  - **三者区分总则**（愤怒/决绝/仇恨必须可辨）：愤怒=爆发外放的热怒（皱眉+怒目+泛红+耸肩前倾）；决绝=平静收敛的坚定（**眉头平展无皱**+专注聚焦+纹丝不动）；仇恨=阴冷压抑的狠意（表面平静+阴冷直盯+呼吸刻意平稳+冷笑）
  - **标注规范**：每格角落标注英文情绪名（FEAR/ANGER/...），小号无衬线；**禁止中文标注**（生图模型中文弱）
  - 每格：正面面部特写（头颈部），发型/妆容/标志性特征一致
- 生成规格：16:9 横版，2K
- **格式契约（强制）**：任何形态（十情绪卡/精简卡/表情表）都必须**完整分条技能提示词结构**（技能1-8 + 限制 + 生成规格，可粘贴图生图），禁止只输出表格/纯文字列表
- **统一 6 格精简版（所有角色，2026-08-14 用户决定：不存在主角/配角之分）**：2行×3列 = **6 个峰值情绪，必须按角色实际情绪锁死具体 6 个**（如小优：急切/轻愣/警觉/犹豫/放松/震惊危机），**禁止通用化凑「喜怒哀乐+2」**；从情绪时间轴/剧本取角色真实峰值情绪；英文标注不变，禁止退化成纯表格；旁白/道具角色跳过（无面部）
  - **默认 6 情绪模板（用户确认 2026-08-14）**：当角色**没有情绪时间轴/剧本情绪数据**时，用默认模板——**平静 / 喜悦 / 愤怒 / 悲伤 / 惊讶 / 警觉**；标注「（默认模板，可按角色剧情调整）」；有情绪数据的角色优先用真实情绪，不用默认

## 四、美术风格与反向词互斥（核心规则）

### 1. 风格→反向词映射表（强制）

| 美术风格（正向锚定词） | 风格互斥反向词（必须加） | 不得出现的反向词 |
|---|---|---|
| 写实真人 | 卡通、插画、动漫、二次元、3D渲染、游戏CG、塑料感 | —（写实自身合法） |
| 二次元/动漫 | 写实、真人、照片、3D渲染、电影质感、皮克斯风 | 卡通、插画（正向自身） |
| 3D卡通渲染 | 写实真人、平面插画、二次元赛璐璐、照片感 | 卡通、3D（正向自身） |
| 水墨/国风 | 写实、油画、厚涂、3D渲染 | 水墨、国风（正向自身） |
| 其他风格 | 反向 = 所有其他风格类别 | 正向风格自身词 |

**判定规则**：先问清美术风格 → 正向锚定词=该风格 → 反向词=「所有不属于该风格的类别」→ 正向风格自身词**绝不能**出现在反向词里。

### 2. 通用四分类反向词库（与风格无关，任何风格都加）

```
质量类     低画质、噪点、模糊、过度磨皮、塑料皮肤、分辨率低

场景漂移类 杂乱背景、多余人物、文字、水印、logo、边框（+题材微调：古装禁现代物品，都市禁古装/宫廷）
细节失控类 服装飘动、强风、衣摆飞扬、配饰晃动
```

## 五、填写规则

### 1. 素体内衣层
- 「内衣层」= 角色最贴身的素衣/中衣状态（去外袍铠甲装饰）。
- 必须包含：体型、发型、面部（静态结构）、肤色、标志性特征、气质底色。
- 原文未描写体型/肤色 → 合理默认 + 标注「（默认，可按参考图替换）」。
- **美术风格必须先确认**（SKILL.md 第零步提问）。
- **面部只写静态结构，禁神情/情绪词**；气质底色用长期稳定词；提示词含「中性表情，目视镜头，无特定情绪」。
- **标志性特征必须内化进技能段，禁止单独列「补充/备注」小节**（2026-08-14 用户指出）：义体/纹身/胎记/随身道具等标志性特征，按位置并入技能4（面部特征如义眼）、技能5（发型）、技能6（服装槽位如机械臂）或技能2（体型如义肢）；角色卡只输出 Part 提示词，任何「补充说明」段落都是落卡违规。

### 2. 服装线
- 按章节时间严格排序，不得乱序。
- 每个换装事件 = 一张新服装卡；状态变化（破损/染血）写入状态变化字段，不单独成卡。
- 服装槽位化：外穿→内搭→腰间→斜挎→下装→鞋，每槽=款式+颜色+材质+质感词+配件；**无对应槽位可省略，不硬凑**。
- 每种材质配质感词（微皱肌理/柔软触感/自然纹理/金属反光/哑光皮质）。
- 服装提示词中长相+气质/发型与素体一致，标志性特征不得丢失。

### 3. 表情库
- 从情绪时间轴反向提取 5-8 个剧情峰值表情。
- 情绪映射用 movie-create-drama-emotion 10 情绪名+强度（轻度/中度/高度）。
- 面部提示词=情绪生理表现表节选+角色化细节，写肌肉/生理变化。

### 4. 一致性约束
- 素体标志性特征在任何服装/三视图中不得丢失。
- 所有色值标注「（文字推断）」并给出备选。
- 三视图顺序铁律与一致性契约（见结构模板第七章）。

## 六、三视图规范（图生图，按顺序执行）

1. **顺序铁律**：全身三视图 → 面部三视图（面部参考全身输出，禁止跳序）。
2. **一致性契约（4 条）**：
   - 人物字段逐字继承（面部复用全身的「技能4·人物」描述，不重写）
   - 参考图传递链单向：素体图 → 全身三视图输出 → 面部三视图参考
   - 视角方向统一（锁死，2026-08-14 实测：老陈前左右 vs 小优前右后方向不一致）：**三视图必须全部面向镜头左侧**——A正面（微左侧）/B=90°左侧面/C背面；禁止右转向（前右后）。写法：「三视角统一面向镜头左侧（A正面/B左90°侧/C背面），禁止右侧视角」；进技能2 排布 + 负面词加「右侧视角/方向不统一」
   - 全链中性表情（情绪只进表情库）
3. **格式**：分条技能结构；生成规格明确比例（16:9 横版三联）。
4. **布局规范**：三幅并排，A/B/C 分配，两条细竖线分隔（不压角色），面板上方居中标注 A-正面/B-侧面/C-背面（或 A/B/C）。
