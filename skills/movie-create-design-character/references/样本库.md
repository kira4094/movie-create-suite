# 角色卡样本库（design-character 私有积累）

> **用途**：每次生成角色卡并经出图验证后，追加一条样本。新角色生成时先查本库找"相似题材+风格"样本，继承已验证的有效句式，避免重踩坑。
> **记录时机**：角色卡出图后，用户反馈效果（好/差/差在哪）→ 提炼有效句式与踩坑 → 追加一条。
> **原则**：只记验证过的事实与句式，不写未验证的猜测。

---

## 样本 1｜采药女医师（古风·写实·市井）

- **题材/风格**：古装奇幻 / 写实电影质感 / 市井采药女
- **出图效果**：✅ 通过（用户：比参考提示词好，有质感）
- **关键有效句式**：
  - 体型矛盾修饰："身形圆润敦实但比例协调"（比单纯"微胖"更易出好比例）
  - 材质质感词："水洗棉麻的微皱肌理、软糯纯棉的柔软触感、竹编的自然纹理、铜铃的细腻金属反光"（每种材质一个质感词，远胜"质感好"）
  - 服装拆槽："外穿/内搭/腰间垂挂/斜挎/下装/鞋"六槽各一句
  - 反向词库分四类：质量类/一致性类/场景漂移类/细节失控类
- **踩坑**：
  - 早期"没有质感"→ 拆成 PBR/微表面/体积光/胶片颗粒渲染特征后改善
  - 身材漂移 → 用多视图锚定 Part 1
- **参考**：已验证角色卡《赤鸦》（赛博朋克·精简四 Part 同结构验证）

## 追加模板（新样本照此格式追加）

```
## 样本 N｜{角色名}（{题材}·{风格}·{定位}）

- **题材/风格**：{题材} / {风格} / {定位一句话}
- **出图效果**：✅ 通过 / ⚠️ 部分 / ❌ 待修（用户点评一句）
- **关键有效句式**：
  - {验证过好用的句子 1}
  - {验证过好用的句子 2}
- **踩坑**：
  - {这次发现的问题 + 解法}
- **参考**：{对应角色卡文件位置}
```
