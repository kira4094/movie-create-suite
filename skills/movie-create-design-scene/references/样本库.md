# 场景卡样本库（design-scene 私有积累）

> **用途**：每次生成场景卡并经出图验证后，追加一条样本。新场景生成时先查本库找"相似题材+风格"样本，继承已验证的有效句式，避免重踩坑。
> **记录时机**：场景卡出图后，用户反馈效果（好/差/差在哪）→ 提炼有效句式与踩坑 → 追加一条。
> **原则**：只记验证过的事实与句式，不写未验证的猜测。

---

## 样本 1｜深山采药山居（古风·写实·俯视）

- **题材/风格**：古风山水 / 写实电影质感 / 高空45°俯视超远景
- **出图效果**：✅ 通过（用户：比参考提示词好，氛围清幽）
- **关键有效句式**：
  - **方位制四分区**（俯视超远景推荐）："南前庭（竹门+落花枯叶）、左主屋（回廊+古井）、北药圃（分畦+小木棚）、右偏檐（躺椅+瓦盆）"——每区=位置+具体物件，模型填空有依据
  - **穿越元素从X到Y**："轻轨从西区出发斜向东南穿过画面中央止于东区"——穿越线是俯视构图唯一能动的线
  - **活着的证据·田园**："飞鸟/落叶（随季节）/花卉颜色点缀/溪流/炊烟"——抽象"清幽"→具体锚点
  - 画风锚定块四件套："流派+渲染特征(PBR/GI/微表面/体积光)+电影参考+质感禁令"
- **踩坑**：
  - 早期"没有质感"→ 拆渲染特征后改善
  - 超远景看不到地面细节 → 生活痕迹按视角分级（超远景=宏观光斑/肌理）
- **参考**：已验证场景卡《深山采药山居》（古风·高空45°俯视超远景）

## 样本 2｜赛博城市夜雨（科幻·写实·俯视大远景）

- **题材/风格**：赛博朋克 / 写实电影质感 / 高空45°俯视超远景·夜间微雨
- **出图效果**：✅ 通过（v6 用户验收：比 v5 氛围好太多）
- **关键有效句式**：
  - **方位制四分区**：北CBD/东滨河/南老城/西枢纽，每区3+物件锚点
  - **空中动态元素是分水岭**："飞行器灯点密布如星/广告热气球/悬浮发光体"——一加氛围立刻活
  - **永不停歇的运转感给具体锚点**："轻轨光轨/飞行器光点/江面船只/24h灯火"——不能只写"永不停歇"四字
  - **视觉中心定位**："画面中央偏北的CBD群与全息投影（最亮），向四周暗部衰减"
  - 明暗对比极致：主色调压暗+霓虹集中功能节点（2077式）
- **踩坑**：
  - v5 缺空中动态 → 像概念空壳都市
  - 版权名（赛博朋克2077/银翼杀手）→ 触发审核，用泛化描述
- **参考**：D:\Projects\TolariaData\（赛博城市测试）
