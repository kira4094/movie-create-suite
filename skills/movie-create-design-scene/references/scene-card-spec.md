# 场景卡数据模型与输出规范（scene-card-spec）

> 本文档定义**场景卡的完整数据模型与输出模板**，供 SKILL.md 的 Phase 3 调用。
> 目标：产出可直接用于「无限画布 / 文生图」生成场景参考图的场景卡，保证同一场景在整部小说中**视觉统一**，且场景变化（如大殿被毁）有独立的生成依据。

---

## 一、设计原则

1. **证据源 = 小说文本**：movie-create-design-style 用截图证据，场景卡用**小说原文段落**作为唯一证据源。每个场景卡必须引用原文关键描写段落，逐段提取特征。
2. **场景本体 × 叙事状态双层分离（防降格铁律）**：小说常以角色视角描写，叙事焦点全在小处（角落、道具、情绪）——**叙事焦点 ≠ 场景本体**。场景卡必须先由场景名+世界观回推场景本体（如「{仙宫}」→ 恢宏仙宫：玉白、鎏金、盘龙柱、高穹顶），再叠加当前章节的叙事状态（角落/被毁/夜/昏暗）。提示词比例：**本体 70%+，状态 30%-**。
3. **色彩动态处理**：只有用户或权威 style-guide 给出 HEX 时才写 HEX；无来源时使用中文颜色关系，不编造色值。
4. **视觉五段式提示词（文生图专用）**：场景提示词**只保留驱动画面的五段**（构图段先查 `../../shared/shot-size-library.md` 定景别×机位）——风格与美学设定 / 构图与空间关系 / 光影与曝光 / 材质细节 / 色彩系统 + 生成规格。
   - **禁止**在提示词中出现「场景与叙事」段（叙事信息放入基本信息区）与「运镜建议」（运镜完全属于视频阶段，移到剧情脚本每场）。
   - **视觉段必须覆盖有效锚点**：风格、空间、光影、材质均须有可执行描述；最终基础模型 payload ≤2700 字符。
5. **比例变量**：用户未声明时默认 4:3；显式声明 9:16 或 16:9 时只保留该比例，不同时写默认 4:3。
6. **场景变化线独立成卡**：同一场景的显著状态变化（被毁/夜晚/下雪）各自独立成一张子卡，防止状态混用导致穿帮。

---

## 二、场景卡结构（单一场景卡，不分 Part，2026-08-14 用户确定）

> **场景卡 = 一个完整文件**（不分 Part A/B/C），包含：头部备注 + **硬性 4 段 + 正文二选一** + 变化线小节（如有）+ 关键道具小节（如有）。
> 基本信息/原文证据/场景特征矩阵/场景本体推断 → 均为**内部提炼**（供提示词取材），不单独落卡。
> **正文二选一**（2026-08-17 实测定案：三场景对比 A完整 vs B精简 效果持平）——**两种模式都是完整提示词格式（非可跳过，硬性 4 段都保留），只切换正文详细度**：
> - **[1] 视觉五段式完整版**——按 style-guide 或用户要求选择材质、体积光、HEX 与尺度锚定，适合复杂材质/特殊光影场景
> - **[2] 精简 6 段版**——风格/景别视角/具体场景/氛围/光线/负面（风格段内联母提示词含色彩+材质），轻量够用（三场景实测与完整版持平）
> - 用户明确或素材复杂 → [1]；默认 → [2]（简短省 token，效果经实测验证）
> - ⚠️ 此处"精简"指**正文段数**，与角色卡"省描述章节"不同；参考图映射、一致性铁律、图片对齐、生成规格在两种模式中都必须保留

先渲染共同头部，再在内部二选一追加一种正文。下面的“内部选项”标题只用于编排，不得写入交付卡；最终卡不得出现“硬性 4 段”“正文二选一”或“模式 [1]/[2]”等合同标签。

```
# 场景卡：{场景名}

> 题材：{题材词} ｜ 画幅：{目标比例；未声明时默认 4:3} ｜ 出现章节：{第1章, 第3章...}

参考图映射：{无（文生图首图）｜真实已生成并将在本次生成中附带的图片资产：{图片文件名或可定位资产标识}}
一致性铁律（强制）：{无真实参考图时，以本卡「构图与空间关系」中的完整文字空间骨架为唯一基准；有真实参考图时，保持已声明图片中的空间或角色特征一致}
图片对齐：{无（Text-to-Image 首图）｜{真实图片资产标识}作为已绑定的空间/角色参考图}
生成规格：{目标比例；未声明时默认 4:3}；空镜，无人物
```

### 内部选项 1：视觉五段式完整版（标题不落卡）

```
布局：{空镜=纯场景构图｜带人物=人物位置/比例/动作}
画面内容：{空镜标准：无人物无文字干净构图｜带人物：人物出现位置/比例/动作}
风格质感：{完整内联已确定的风格；无风格则写中性材质与光线}
风格与美学设定：{核心精神与画风锚点，覆盖色彩/材质/光学结果}
构图与空间关系：{尺度锚定与空间反例}——**先查 `../../shared/shot-size-library.md` 选景别×机位**：场景本体默认大远景 + 高空45°俯视或平视；变化线继承本体；带人物版用中景或全身景；关键道具用大特写。机位描述用相对语言（平视/仰角/俯角），禁精确距离角度。**空间蓝图内化**：若先运行了 movie-create-design-scene-layout（宏观空间蓝图），须把其空间骨架写进本段——区分功能分区、主体结构（墙/柱/窗/门）、角色活动区/泊位、光位来源方向、空间尺度锚定（相邻物体比例），骨架先于质感（结构对了再谈材质光影），避免模型画成抽象大堂或破败角落
光影与曝光：{主光、辅光、阴影、曝光与视觉结果}
材质细节（三层描述法）：{每种材质保留基础、一个微表面和一个光学结果}
色彩系统：{主色/辅助/点缀；HEX 仅在来源提供时写}
负面提示词：{完整写入已确定的风格冲突项 + 场景专属禁令；不得覆盖明确正向风格}
```

### 内部选项 2：精简六段版（标题不落卡）

```
风格：{从风格定义库提炼母提示词内联——核心哲学 + 色彩系统 + 材质语汇，1-3 句（如 009 后末日："旧秩序崩塌后幸存者在文明残骸上重建；灰白/尘黄/锈红/褪色蓝底色；裂缝混凝土、锈铁、旧塑料与厚尘，器物被用旧补过重新组装"）。**不写风格编号**（模型只认内容不认编号）}
景别+视角：{如：全景，平视}
具体场景：{地点}——{核心元素 3-5 个，一句带过}
氛围：{情绪基调 1 句}
光线：{光源+时段 1 句}
负面提示词：{简版 8-10 词}
```

存在状态变化时，再追加以下内容；每个变体必须自包含，不得引用“本卡正文”“硬性 4 段”“五段式正文”或“继承基线”。

```
## 变化线
- 变体 1：{状态名}（{第X章}起）——{与原场景差异}
- 变体 1 提示词：{完整写入固定空间骨架、材质、光色基底与本变体状态，形成可独立粘贴的提示词}
- 本体保持：{场景本体（形制/材质/色彩基底）不变，只变状态}

## 关键道具
- {道具名}：{简版提示词（风格/光影/材质/色彩），一次性道具只列描述不单独出图}
```

> **编译期与运行期边界（硬规则）**：`.movie-create/scene-layout/*.md`、其中的 ASCII 平面图和宏观出图提示词都是构建场景卡时读取的文字中间态。它们不是图片资产，不得直接写成 `[@资产]`、`<Picture N>` 或“参考图”。最终场景卡必须把蓝图中的空间形状与尺度、主体结构、前中后景/方位、功能区、空置活动区、光位方向、固定道具位置、相邻尺度、确认机位和错误空间反例完整写入「构图与空间关系」，使单文件可独立进行 Text-to-Image。
>
> 最终场景卡只有两种运行状态：A. 无真实图片绑定（默认 T2I 首图）；B. 真实图片已经生成、可定位且会随请求附带。内部可以记录“蓝图已生成但确认图未生成”的阶段，但不得把它作为第三种交付格式。
>
> **真实图片门槛**：只有存在实际图片文件/平台资产标识，且本次请求确实会附带时，才可填写图片资产。规范正文保持模型中立，不持久化 `<Picture N>`；具体平台适配层再将中性资产声明转换为模型参数。

**输出规则**：
1. **单一文件，不分 Part**——硬四段 + 内部选定的五段或六段正文，再加变化线与关键道具（如有）；模式不写入交付卡
2. 空镜版默认（无人物）；带人物版仅在用户明确要求时用（需引用角色卡 + 双一致性铁律）
3. 变化线/关键道具**有才写**（没有就不写小节），正文详略由内部参数决定
4. 生成规格使用 `{目标比例与方向}`，必须渲染为 `9:16 竖屏`、`16:9 横屏` 或默认 `4:3`；用户未声明时使用默认 4:3
5. 风格质感/视觉五段式正文/负面提示词为**完整内容**，禁止"同上文/继承"引用（模型只看到单文件）

## 三、填写规则

### 1. 原文证据（内部提炼，不落卡）
- 每个场景卡至少引用 1 段原文；多次出现的场景引用首现段 + 关键变化段。
- 原文引用用于内部审计与特征提取，**不写入输出文件**。

### 2. 特征矩阵（内部提炼，不落卡，信息进主场景各段）
- 每个维度必须填值（空间结构/主体环境/光源/材质/关键道具/情绪基调）；原文未描写时在内部选择保守、具体且可验证的值，直接写入场景卡，不写“未描写”“默认”或“可替换”。
- 禁止从其他场景/常识推断本场景特征——只认原文。
- **必须做「场景本体推断」**（防降格铁律，内化进主场景风格段）：由场景名+世界观回推本体（空间尺度/建筑风格/材质基调/主色调），并与叙事状态（角落/破败/光暗）分开。叙事焦点（角色视角看到的小处）不得直接等同于场景本体——本体 70%+ 状态 30%- 体现在提示词比例，而非输出小节。

### 3. 视觉五段式提示词（核心）
- **只写五段**：风格与美学设定 / 构图与空间关系 / 光影与曝光 / 材质细节 / 色彩系统 + 生成规格。**禁止「场景与叙事」段、禁止「运镜建议」行**——叙事信息放基本信息区「叙事定位」，运镜在剧情脚本每场标注。
- **字数预算（硬指标）**：基础场景最终提示词≤2700 Unicode code points；每个变化线提示词≤1200。压缩时保留空间骨架、相邻尺度、机位、主光和材质锚点。
- **每段强制模板**（这是「没有质感」的根治规则——抽象词如"写实/电影质感"模型无法转化，必须拆成可执行的渲染特征描述）：

**① 风格与美学设定段 → 画风锚定块（强制四件套）**
```
[美术流派] + [渲染质感关键词] + [电影参考锚定] + [质感禁令]
- 美术流派：写死流派（中国古典仙侠殿堂/赛博仙侠/水墨风…），不给模型猜
- 渲染特征（替代抽象“质感”词）：按 style-guide 或用户选择动态填写；无来源时写可见材质、光线与空间关系
- 电影参考锚定：仅在用户确实提供电影参考时填写具体参考体系；未提供时不自行补充影片名称
- 质感禁令（负面排除）：仅继承 style-guide 或用户明确的限制；不得默认禁用卡通、3D 或塑料高光
```

**② 构图与空间关系段 → 尺度锚定 + 空间反例**
```
[原有结构描述]
+ 尺度锚定（强制写）：
- 殿顶高度：画面纵向取景比例（如殿高占1/2，实际殿高约8-10人叠立）
- 柱径：单柱占画面宽度比例（如1/8），两侧柱列近大远小透视
- 人物参照：若放入一人仅及柱径1/3——强调巨型尺度
- 视觉压迫感：低机位仰角约15°，柱体向中心微倾，"人被建筑吞没"
+ 空间反例排除：禁止低矮天花板/狭小空间感/平面构图/缺少透视纵深
```

**②-2 方位制四分区（俯视超远景推荐写法，与近/中/远并列按视角选）**
> 实战验证：俯视超远景下「近/中/远」深度轴被压扁，模型易画成三层叠放；**方位制是俯视图的真实逻辑**（俯视下"远"≈画面上方），四方铺满画面零遗漏，穿越元素天然支持。
```
构图与空间关系：高空45°俯视超远景，全景鸟瞰。
四方分区（每区 = 区属性 + ≥3 个具体物件锚点）：
· 北区（画面上方）= {功能区}——{3+ 物件锚点}
· 东区（画面右方）= {功能区}——{3+ 物件锚点}
· 南区（画面下方）= {功能区}——{3+ 物件锚点}
· 西区（画面左方）= {功能区}——{3+ 物件锚点}
穿越元素（从X到Y，明确起止方位，画面即活）：
· {轻轨/河道/高架}从{西}区出发，斜向{东南}穿过画面中央，止于{东}区
· {第二条穿越线}……
视觉中心：画面{中央偏X}的{最亮主体}，向四周暗部衰减
```

**②-3 穿越元素（轨道/河道/车流必须给"从X到Y"）**
> 穿越元素是俯视构图里唯一能"动"起来的线，写死起止方位（从西到东南斜穿），模型才能画出穿透感而非悬浮感。静止的轨道 = 死城。

**②-4 活着的证据（通用铁律，所有场景必写）+ 按世界观分类清单**
> **通用铁律（由赛博城市 v6 实战验证提炼，适用于所有场景）**：
> 1. **任何场景都必须有"活着的证据"**——证明这个世界在被使用/有生命，不能是空壳/死景。抽象词（"有生活气息"/"永不停歇"/"清幽"）模型无法转化，**必须给具体动态锚点或物证**。
> 2. **证据形式按世界观类型分发**，不是赛博专属——看下面的分类清单。
> 3. **生活痕迹按视角分级**：超远景=宏观痕迹（光斑/密度/肌理），中景=物证（水塔/器物/招牌），近景=微观细节（行人/烟火/微小动静）。
```
超远景 = 宏观痕迹：光斑分布/街区肌理/动态密度（城市窗光密度、夜市光团、飞行器灯点）
中景   = 生活物证：楼顶水塔/空调外机群/招牌/晾晒/器物
近景   = 微观细节：行人/摊位烟火/落叶/飞鸟/涟漪
```

**按世界观分类的"活着的证据"清单（按场景世界观取对应一类，发散想象力）**：
```
· 田园山居/乡野：自然生机派——飞鸟/虫鸣/落叶（跟随季节）/花卉颜色点缀/溪流/炊烟/晾晒物/家畜/风过草木
· 都市/现代：人的无序 vs 城市有序——人群流动/车辆/店铺灯光/通勤潮/烟火气/晾晒/外卖骑手/霓虹招牌
· 赛博/科幻：高科技日常化——飞行载具/广告热气球/无人机物流/不规则科幻建筑/永不停歇运转感（车流光轨/飞行器灯点如星/广告屏不熄/24h灯火）
· 仙侠/奇幻：灵力痕迹——灵气光点/浮空物/仙鹤灵兽/云雾缭绕/法阵微光/天材地宝灵光
· 战争/废墟：残骸与生机对比——硝烟/断壁/野草重生/寒鸦/零星灯火/幸存者痕迹
· 太空/异星：人造物与荒芜对比——轨道站灯光/尘埃星云/基地灯火/机械运转声痕/外星植被异色
```
> **发散规则**：拿到场景先问"这个世界靠什么活着/在被谁使用"→ 按世界观类型选清单 → **具体化到看得见摸得着的锚点**（不是"有生气"而是"竹竿晾着蓝布衣，风掀衣角"）。季节/时间变量也在此体现（落叶↔繁花↔积雪，晨露↔夜灯）。

> **实战标杆（2026-08-12 赛博城市 v6，用户验收通过）**：方位制四分区+穿越元素+想象力清单三者组合，出图氛围显著优于 v5（近/中/远+无空中动态）。
> MCP 对比验证（v5 vs v6）：v5 缺飞行器/热气球/空中光点、不规则建筑形态，"永不停歇"感空泛；v6 有轻轨光轨/飞行器光点/悬浮发光体、CBD不规则科幻形态+老城对比、江面船只+全域灯火营造永动感。
> 规律：**"活着的证据"必须给具体动态锚点，不能只写抽象形容词；空中/环境动态元素是超远景场景氛围的分水岭**（赛博=飞行器，田园=飞鸟，仙侠=灵气光点）。

**③ 光影与曝光段 → 体积感六要素（强制逐项）**
```
1. 主光源：类型+位置+色温+入射角（如殿侧高窗射入暖金色日光CCT约4500K，斜45°）
2. 体积光：光柱宽度+浮尘可见度+边缘衰减（数千微尘粒子缓慢翻滚，边缘虚化自然衰减）
3. 高光溢出：光束直射区域轻微过曝成光池，边缘羽化过渡
4. 阴影层次：三层递进（柱背RGB约25-35 / 穹顶RGB约15-25 / 深处RGB约8-15 非死黑可见暗纹）
5. 间接光照：地面反光反弹至柱面下部/墙底——环境光二次反弹而非额外光源
6. 曝光策略：低ISO(400)干净暗部 + 高光不溢出 + 电影级宽容度
```

**④ 材质细节段 → 三层描述法（每种材质强制三层）**
```
每种材质写三层（基础+微表面+光学）：
1. {材质名}：
   - 基础：{材质种类+尺寸+砌法+颜色}（如金砖墁地，单砖一步见方，砖缝细如发丝，金粉填缝）
   - 微表面：{反光性质+表面痕迹}（镜面级反射倒映柱影，千年踩踏微凹但光洁——非破败，是"使用的庄严感"）
   - 光学：{受光表现}（暖金反光将柱底染成铜色，光池边缘反射率接近水面）
2. {下一材质}：同上三层
（至少覆盖：地面/柱体/穹顶/墙面/布幔/场景特有材质）
```

**⑤ 色彩系统**：保留现有结构（主/辅/点 + 关系 + 备选）。

- **反例排除词**：仅在 style-guide 或用户明确提供时写排除词；正向风格特征优先，禁止词不得跨风格固化。
- **防降格检查（强制）**：场景名含「仙宫/皇城/神殿/宗门/天阙」等宏大词时——① 必须含宏伟尺度词（高挑穹顶/巨型石柱/玉石/鎏金/透视纵深）；② 色彩用高明度系（白玉/鎏金/天青类），禁止灰棕暗色系作为主体；③ 场景本体层禁止「磨损/破败/简陋/昏暗」等降格词，降格状态只允许出现在叙事状态层；④ 场景名自带的视觉锚点必须提取（如「紫极」→紫色点缀、「天阙」→天门）。
- 有 HEX 来源时记录 #RRGGBB 与中文描述；无来源时只写面积、明度、冷暖、载体与叙事功能，不强制 HEX。
- 禁止暗角/边缘渐暗写入正向规则（movie-create-design-style 全局排除项）。
- 生成规格未声明时默认 4:3；用户明确 9:16 或 16:9 时只保留声明比例。

### 4. 关键道具
- 贯穿道具（多次出现、有伏笔功能）→ 独立提示词。
- 一次性道具 → 列表描述即可。
- 道具提示词简版：风格与美学设定 / 光影与曝光 / 材质细节 / 色彩系统（可省略构图段）。

### 5. 场景变化线
- 变化线是「同一物理空间的显著状态变体」，不是新场景。
- 每张变体卡必须完整写入固定空间骨架、材质、色彩与机位，并明确“本体保持”；只重写状态变化，不引用基线场景或其他正文段落。
- **本体保持**：变化只动状态（光线/天色/损毁度），场景身份特征（材质/色彩基底/建筑形制）不得丢失。

### 6. 场景命名与去重
- 场景按「物理空间」划分：{场景A}、{场景B}、{场景C}……同一物理空间的内部机位变化不建新卡。
- 全本扫描阶段先建立场景清单，避免同场景多次描写被误拆成多张卡。
