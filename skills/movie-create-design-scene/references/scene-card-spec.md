# 场景卡数据模型与输出规范（scene-card-spec）

> 本文档定义**场景卡的完整数据模型与输出模板**，供 SKILL.md 的 Phase 3 调用。
> 目标：产出可直接用于「无限画布 / 文生图」生成场景参考图的场景卡，保证同一场景在整部小说中**视觉统一**，且场景变化（如大殿被毁）有独立的生成依据。

---

## 一、设计原则

1. **证据源 = 小说文本**：movie-style 用截图证据，场景卡用**小说原文段落**作为唯一证据源。每个场景卡必须引用原文关键描写段落，逐段提取特征。
2. **场景本体 × 叙事状态双层分离（防降格铁律）**：小说常以角色视角描写，叙事焦点全在小处（角落、道具、情绪）——**叙事焦点 ≠ 场景本体**。场景卡必须先由场景名+世界观回推场景本体（如「紫极仙宫」→ 恢宏仙宫：玉白、鎏金、盘龙柱、高穹顶），再叠加当前章节的叙事状态（角落/被毁/夜/昏暗）。提示词比例：**本体 70%+，状态 30%-**。
3. **色彩全部标注「（文字推断）」**：小说无截图 HEX 证据，所有色值为文本推断，必须附 1-2 个备选 HEX 供无限画布阶段人工拍板。
4. **视觉五段式提示词（文生图专用）**：场景提示词**只保留驱动画面的五段**——风格与美学设定 / 构图与空间关系 / 光影与曝光 / 材质细节 / 色彩系统 + 生成规格。
   - **禁止**在提示词中出现「场景与叙事」段（叙事信息放入基本信息区）与「运镜建议」（运镜完全属于视频阶段，移到剧情脚本每场）。
   - **视觉段必须信息密集**：风格美学 ≥150 字、构图空间 ≥150 字、光影曝光 ≥150 字、材质细节 ≥200 字。简短 = 模型自由发挥 = 出烂图。
5. **默认竖屏 9:16**：面向抖音/快手竖屏短剧，场景参考图默认 9:16 竖版、2K。若目标平台为横版，生成规格改为 16:9。
6. **场景变化线独立成卡**：同一场景的显著状态变化（被毁/夜晚/下雪）各自独立成一张子卡，防止状态混用导致穿帮。

---

## 二、场景卡结构（输出模板 = 仅可粘贴提示词，精简版）

> **场景卡只输出可粘贴提示词**（Part A 主场景 / Part B 变化线变体 / Part C 贯穿道具），不输出描述性章节。
> 基本信息/原文证据/场景特征矩阵/场景本体推断 → 均为**内部提炼**（供提示词取材），不单独落卡。
> 信息去向：场景名+出现章节→文件名+头部备注；空间结构→Part A 构图段；光源→Part A 光影段；材质→Part A 材质段；关键道具→Part C；情绪基调→Part A 风格段；本体推断（防降格）→Part A 风格段形制/尺度/色彩倾向。

```
# 场景卡：{场景名}

> 风格：{三选一记录，一行：A movie-style / B 风格库·{风格名} / C 自定义}
> 题材：{题材词} ｜ 画幅：{9:16/16:9} ｜ 出现章节：{第1章, 第3章...}

## Part A 主场景提示词（文生图，9:16）
> 空镜版（默认，无人物）：
```
参考图映射：无（文生图首图）｜有布局蓝图时 [@布局蓝图] → <Picture 1>
一致性铁律（强制）：<Picture 1> 空间结构（墙/柱/窗/分区）全程一致
图片对齐：无（首图）｜布局蓝图对应空间基准
生成规格：9:16 竖版 2K
布局：视觉五段式（风格与美学设定 → 构图与空间关系 → 光影与曝光 → 材质细节 → 色彩系统）
画面内容：风格与美学设定 / 构图与空间关系 / 光影与曝光 / 材质细节 / 色彩系统
风格质感：PBR 写实电影质感 + 画风锚定块四件套
负面提示词：低多边形/卡通/插画/塑料高光/死黑阴影 + 场景专属禁令
```

> 带人物版（用户要求场景中有人物，必须加角色卡参考）：
```
参考图映射：[@角色1] → <Picture 1>（角色卡 Part 1 全身定妆照）
            [@场景1] → <Picture 2>（布局蓝图/场景素材）
一致性铁律（强制）：<Picture 1> 中角色外观全程一致（在场景中的位置/比例/动作除外）
                    <Picture 2> 中场景环境全程一致
图片对齐：<Picture 1> 对应场景中角色基准；<Picture 2> 对应场景环境基准
生成规格：9:16 竖版 2K
布局：视觉五段式 + 人物布局（角色在场景中的位置/比例/动作）
画面内容：五段式 + 人物出现位置/比例/动作
风格质感：同空镜版
负面提示词：同空镜版 + 人物相关禁令
```

## Part B 场景变化线变体（如有）
```
参考图映射：[@基线场景] → <Picture 1>（Part A 主场景）
一致性铁律（强制）：<Picture 1> 场景本体（形制/材质/色彩基底）不变，只变状态
图片对齐：<Picture 1> 对应变化线基线
生成规格：同 Part A
布局：仅变化段落重写，未变段落「继承基线场景」
画面内容：变化段五段式 + 继承标注
风格质感：同 Part A
负面提示词：同 Part A + 状态专属禁令
```

```
参考图映射：视情况（有道具参考图则列）
一致性铁律（强制）：道具外观与参考一致
图片对齐：视情况
生成规格：同场景
布局：风格与美学设定 / 光影与曝光 / 材质细节 / 色彩系统（可省略构图段）
画面内容：道具简版提示词
风格质感：同场景
负面提示词：道具变形/材质错 + 场景负面词
```
```

**提示词字段来源（内部提炼 → 落卡映射）**：
| 内部提炼（不落卡） | 落卡位置 |
|------------------|---------|
| 基本信息（场景名/出现章节/类型/时间/叙事定位） | 文件名 + 头部备注（叙事定位不落卡，仅人读） |
| 原文证据（逐段引用） | 不落卡（审计依据） |
| 空间结构（柱/墙/门/窗/布局） | Part A 构图与空间关系段 |
| 主体与环境关系 | Part A 构图与空间关系段（尺度锚定） |
| 光源与方向 | Part A 光影与曝光段 |
| 材质 | Part A 材质细节段（三层描述法） |
| 关键道具 | Part C 贯穿道具提示词 / 一次性道具不落卡 |
| 情绪基调 | Part A 风格与美学设定段（色彩倾向/氛围） |
| 场景本体推断（防降格） | Part A 风格段（建筑形制/尺度/色彩倾向，本体 70%+ 状态 30%-） |

## 三、填写规则

### 1. 原文证据（内部提炼，不落卡）
- 每个场景卡至少引用 1 段原文；多次出现的场景引用首现段 + 关键变化段。
- 原文引用用于内部审计与特征提取，**不写入输出文件**。

### 2. 特征矩阵（内部提炼，不落卡，信息进 Part A 各段）
- 每个维度必须填值（空间结构/主体环境/光源/材质/关键道具/情绪基调）；原文未描写时写「未描写（默认：...）」，用合理默认并标注可替换。
- 禁止从其他场景/常识推断本场景特征——只认原文。
- **必须做「场景本体推断」**（防降格铁律，内化进 Part A 风格段）：由场景名+世界观回推本体（空间尺度/建筑风格/材质基调/主色调），并与叙事状态（角落/破败/光暗）分开。叙事焦点（角色视角看到的小处）不得直接等同于场景本体——本体 70%+ 状态 30%- 体现在提示词比例，而非输出小节。

### 3. 视觉五段式提示词（核心）
- **只写五段**：风格与美学设定 / 构图与空间关系 / 光影与曝光 / 材质细节 / 色彩系统 + 生成规格。**禁止「场景与叙事」段、禁止「运镜建议」行**——叙事信息放基本信息区「叙事定位」，运镜在剧情脚本每场标注。
- **字数预算（硬指标）**：风格美学 ≥250 字、构图空间 ≥250 字、光影曝光 ≥250 字、材质细节 ≥350 字。未达标 = 提示词不合格，需重写。
- **每段强制模板**（这是「没有质感」的根治规则——抽象词如"写实/电影质感"模型无法转化，必须拆成可执行的渲染特征描述）：

**① 风格与美学设定段 → 画风锚定块（强制四件套）**
```
[美术流派] + [渲染质感关键词] + [电影参考锚定] + [质感禁令]
- 美术流派：写死流派（中国古典仙侠殿堂/赛博仙侠/水墨风…），不给模型猜
- 渲染特征（替代抽象"质感"词）：物理渲染(PBR)级写实、全局光照(GI)间接漫反射、微表面材质反射(roughness/metallic)、体积光(丁达尔光束)、电影级浅景深、35mm胶片微颗粒感
- 电影参考锚定：具体可感的参考体系（如《封神第一部》石材体量感+《英雄》色彩饱和度+《沙丘》体积光与空气感）——参考片帮助模型定位质感层级
- 质感禁令（负面排除）：禁止低多边形/卡通渲染/平面插画风/游戏贴图感/塑料高光/死黑阴影/CG感过重的干净表面
```

**② 构图与空间关系段 → 尺度锚定 + 空间反例**
```
[原有结构描述]
+ 尺度锚定（强制写）：
- 殿顶高度：画面纵向取景比例（如殿高占1/2，实际殿高约8-10人叠立）
- 柱径：单柱占画面宽度比例（如1/8），两侧柱列近大远小透视
- 人物参照：若放入一人仅及柱径1/3——强调巨型尺度
- 视觉压迫感：低机位仰角约15°，柱体向中心微倾，"人被建筑吞没"
+ 空间反例排除：禁止低矮天花板/狭小空间感/平面构图/缺少透视纵深
```

**②-2 方位制四分区（俯视超远景推荐写法，与近/中/远并列按视角选）**
> 实战验证：俯视超远景下「近/中/远」深度轴被压扁，模型易画成三层叠放；**方位制是俯视图的真实逻辑**（俯视下"远"≈画面上方），四方铺满画面零遗漏，穿越元素天然支持。
```
构图与空间关系：高空45°俯视超远景，全景鸟瞰。
四方分区（每区 = 区属性 + ≥3 个具体物件锚点）：
· 北区（画面上方）= {功能区}——{3+ 物件锚点}
· 东区（画面右方）= {功能区}——{3+ 物件锚点}
· 南区（画面下方）= {功能区}——{3+ 物件锚点}
· 西区（画面左方）= {功能区}——{3+ 物件锚点}
穿越元素（从X到Y，明确起止方位，画面即活）：
· {轻轨/河道/高架}从{西}区出发，斜向{东南}穿过画面中央，止于{东}区
· {第二条穿越线}……
视觉中心：画面{中央偏X}的{最亮主体}，向四周暗部衰减
```

**②-3 穿越元素（轨道/河道/车流必须给"从X到Y"）**
> 穿越元素是俯视构图里唯一能"动"起来的线，写死起止方位（从西到东南斜穿），模型才能画出穿透感而非悬浮感。静止的轨道 = 死城。

**②-4 活着的证据（通用铁律，所有场景必写）+ 按世界观分类清单**
> **通用铁律（由赛博城市 v6 实战验证提炼，适用于所有场景）**：
> 1. **任何场景都必须有"活着的证据"**——证明这个世界在被使用/有生命，不能是空壳/死景。抽象词（"有生活气息"/"永不停歇"/"清幽"）模型无法转化，**必须给具体动态锚点或物证**。
> 2. **证据形式按世界观类型分发**，不是赛博专属——看下面的分类清单。
> 3. **生活痕迹按视角分级**：超远景=宏观痕迹（光斑/密度/肌理），中景=物证（水塔/器物/招牌），近景=微观细节（行人/烟火/微小动静）。
```
超远景 = 宏观痕迹：光斑分布/街区肌理/动态密度（城市窗光密度、夜市光团、飞行器灯点）
中景   = 生活物证：楼顶水塔/空调外机群/招牌/晾晒/器物
近景   = 微观细节：行人/摊位烟火/落叶/飞鸟/涟漪
```

**按世界观分类的"活着的证据"清单（按场景世界观取对应一类，发散想象力）**：
```
· 田园山居/乡野：自然生机派——飞鸟/虫鸣/落叶（跟随季节）/花卉颜色点缀/溪流/炊烟/晾晒物/家畜/风过草木
· 都市/现代：人的无序 vs 城市有序——人群流动/车辆/店铺灯光/通勤潮/烟火气/晾晒/外卖骑手/霓虹招牌
· 赛博/科幻：高科技日常化——飞行载具/广告热气球/无人机物流/不规则科幻建筑/永不停歇运转感（车流光轨/飞行器灯点如星/广告屏不熄/24h灯火）
· 仙侠/奇幻：灵力痕迹——灵气光点/浮空物/仙鹤灵兽/云雾缭绕/法阵微光/天材地宝灵光
· 战争/废墟：残骸与生机对比——硝烟/断壁/野草重生/寒鸦/零星灯火/幸存者痕迹
· 太空/异星：人造物与荒芜对比——轨道站灯光/尘埃星云/基地灯火/机械运转声痕/外星植被异色
```
> **发散规则**：拿到场景先问"这个世界靠什么活着/在被谁使用"→ 按世界观类型选清单 → **具体化到看得见摸得着的锚点**（不是"有生气"而是"竹竿晾着蓝布衣，风掀衣角"）。季节/时间变量也在此体现（落叶↔繁花↔积雪，晨露↔夜灯）。

> **实战标杆（2026-08-12 赛博城市 v6，用户验收通过）**：方位制四分区+穿越元素+想象力清单三者组合，出图氛围显著优于 v5（近/中/远+无空中动态）。
> MCP 对比验证（v5 vs v6）：v5 缺飞行器/热气球/空中光点、不规则建筑形态，"永不停歇"感空泛；v6 有轻轨光轨/飞行器光点/悬浮发光体、CBD不规则科幻形态+老城对比、江面船只+全域灯火营造永动感。
> 规律：**"活着的证据"必须给具体动态锚点，不能只写抽象形容词；空中/环境动态元素是超远景场景氛围的分水岭**（赛博=飞行器，田园=飞鸟，仙侠=灵气光点）。

**③ 光影与曝光段 → 体积感六要素（强制逐项）**
```
1. 主光源：类型+位置+色温+入射角（如殿侧高窗射入暖金色日光CCT约4500K，斜45°）
2. 体积光：光柱宽度+浮尘可见度+边缘衰减（数千微尘粒子缓慢翻滚，边缘虚化自然衰减）
3. 高光溢出：光束直射区域轻微过曝成光池，边缘羽化过渡
4. 阴影层次：三层递进（柱背RGB约25-35 / 穹顶RGB约15-25 / 深处RGB约8-15 非死黑可见暗纹）
5. 间接光照：地面反光反弹至柱面下部/墙底——环境光二次反弹而非额外光源
6. 曝光策略：低ISO(400)干净暗部 + 高光不溢出 + 电影级宽容度
```

**④ 材质细节段 → 三层描述法（每种材质强制三层）**
```
每种材质写三层（基础+微表面+光学）：
1. {材质名}：
   - 基础：{材质种类+尺寸+砌法+颜色}（如金砖墁地，单砖一步见方，砖缝细如发丝，金粉填缝）
   - 微表面：{反光性质+表面痕迹}（镜面级反射倒映柱影，千年踩踏微凹但光洁——非破败，是"使用的庄严感"）
   - 光学：{受光表现}（暖金反光将柱底染成铜色，光池边缘反射率接近水面）
2. {下一材质}：同上三层
（至少覆盖：地面/柱体/穹顶/墙面/布幔/场景特有材质）
```

**⑤ 色彩系统**：保留现有结构（主/辅/点 + 关系 + 备选）。

- **反例排除词**：风格与美学设定段末尾必须写「禁止……」排除词（如禁止破旧/颓败/废墟/地牢感/西方哥特），材质段必须写质感禁令（禁止塑料高光/游戏贴图感/卡通渲染）。
- **防降格检查（强制）**：场景名含「仙宫/皇城/神殿/宗门/天阙」等宏大词时——① 必须含宏伟尺度词（高挑穹顶/巨型石柱/玉石/鎏金/透视纵深）；② 色彩用高明度系（白玉/鎏金/天青类），禁止灰棕暗色系作为主体；③ 场景本体层禁止「磨损/破败/简陋/昏暗」等降格词，降格状态只允许出现在叙事状态层；④ 场景名自带的视觉锚点必须提取（如「紫极」→紫色点缀、「天阙」→天门）。
- 所有颜色必须 HEX #RRGGBB + 中文描述 + 面积 + 明度 + 冷暖 + 载体 + 叙事功能；禁止 HSV/HSB 表达（遵循 movie-style 规范）。
- 禁止暗角/边缘渐暗写入正向规则（movie-style 全局排除项）。
- 生成规格默认 9:16 竖版（竖屏短剧平台）；用户明确横版时改 16:9。

### 4. 关键道具
- 贯穿道具（多次出现、有伏笔功能）→ 独立提示词。
- 一次性道具 → 列表描述即可。
- 道具提示词简版：风格与美学设定 / 光影与曝光 / 材质细节 / 色彩系统（可省略构图段）。

### 5. 场景变化线
- 变化线是「同一物理空间的显著状态变体」，不是新场景。
- 每张变体卡复用基线场景的视觉五段式中未变段落，只重写变化段落，并注明「继承基线场景」。
- **本体保持**：变化只动状态（光线/天色/损毁度），场景身份特征（材质/色彩基底/建筑形制）不得丢失。

### 6. 场景命名与去重
- 场景按「物理空间」划分：紫极仙宫偏殿、紫极仙宫大殿、山门、云海天阙……同一物理空间的内部机位变化不建新卡。
- 全本扫描阶段先建立场景清单，避免同场景多次描写被误拆成多张卡。

## 四、与 movie-style 的衔接

场景卡产出后进入无限画布/文生图阶段：
1. 直接用「视觉五段式提示词」生成场景参考图（TextToImage，无参考）。
2. 场景参考图确认后，作为视频生成阶段的背景参考：`参考<图片N>中的场景`（图生视频）。
3. 场景变化线变体 = 独立提示词生成，不依赖基线场景图做 ImageToImage（避免状态污染），除非用户指定要基图衍生。

> 若环境无图像生成器：降级交付「场景卡 + 五段式提示词 + 生成规格」，不虚构图像产出。
