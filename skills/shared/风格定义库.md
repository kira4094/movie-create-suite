# 风格定义库（shared 共享）

> **用途**：生成角色卡/场景卡/视频提示词前，先查本库理解**风格的精神内核**——不是堆表层元素，而是抓住每个风格的灵魂。语汇库给"元素"，本库给"灵魂"。
> **来源**：并行调研 agent 深度定义（2026-08-14）+ 项目实战验证。每个风格含 7 维：核心精神/氛围基调/典型场景/材质语汇/光影/色彩/反面清单。
> **用法**：风格段先写「核心精神一句话」锚定气质，再按 7 维取元素——避免"空有元素没有灵魂"（赛博修理铺实测教训：堆了霓虹义体但氛围像温馨工坊）。

## 风格 1：赛博朋克（Cyberpunk）

- **核心精神**：**「高科技低生活」**——技术先进到近乎神迹（全息、义体、巨型企业AI），却救不了任何一个人；财富权力向上浓缩成光污染巨构，生命尊严向下沉入潮湿底层废墟。技术越灿烂，生活越廉价；华丽是遮掩，破败才是真相。
- **氛围基调**：压抑（无处可逃的密度）/ 倦怠认命（被系统消化后的沉默）/ 危机猜疑（监视无处不在）/ 疏离（人潮汹涌却彼此无关）
- **典型场景**：永远下雨的街（霓虹倒映积水）/ 巨型广告下的贫民巷 / 胶囊格子间居所 / 企业塔楼机房 / 地下义体诊所维修铺
- **材质语汇**（核心=**熵增与使用痕迹**，一切高科技必须"用旧了修过快坏"）：锈蚀钢板铁皮 / 裸露老化管线（绝缘层开裂渗水）/ 油污水泥旧混凝土 / 破损塑料老化外壳 / 劣质复合材料（廉价外壳包新技术）/ 坏掉的电子设备（屏幕裂纹像素坏死）/ 灰尘污垢水渍霉斑
- **光影**：霓虹灯管+荧光灯管+全息投影+LED屏做主光；**环境压暗、大片黑死阴影中局部高亮**，光污染刺破黑暗（光更杂更雾更脏）；永远夜晚/雨夜/阴天黄昏，无直射阳光
- **色彩**：主色=低饱和暗青/墨蓝/铁灰/近黑（脏与低生活）；辅助=褪色洋红/暗青绿/灰粉紫（霓虹"老了旧了"）；点缀=荧光青/品红/电黄（高饱和刺目）；**标志性：青（冷/科技/企业）vs 品红橙（暖/廉价/底层）冷暖对冲**；低饱和脏底+高饱和锐利点缀
- **反面清单**：整洁光亮高科技空间（苹果店美学）/ 明亮日景 / 奢侈华丽 / 温暖木质匠人手作 / 自然景观 / 柔美浪漫粉彩 / 极简留白空寂 / 蒸汽朋克黄铜华丽 / 无菌实验室 / 圆润卡通可爱感
- **提示词锚定词**：`赛博朋克 / 高科技低生活 / 雨夜巨构都市 / 锈蚀与裸露管线 / 脏旧材质 / 低饱和暗底+霓虹青粉点缀 / 光污染 / 压抑颓靡 / 夜景无阳光 / 熵增使用痕迹`
- **反向词**：`干净整洁 / 明亮日景 / 奢华华丽 / 木质工坊 / 自然景观 / 柔光浪漫 / 极简留白 / 全新无痕`

> **核心铁律**：所有「高科技」元素必须呈现劣化状态（旧/脏/修过/快坏）——这是区分真赛博朋克与"空有霓虹"表层模仿的关键。

## 风格 2：古风仙侠（Xianxia）

- **核心精神**：**「仙气×写实」的平衡——仙而不假，实而不俗**。以道家"道法自然、虚静空灵"为精神内核，用写实的物理质感承载超脱的想象。仙气来自光影/留白/灵气微光的克制运用，真实感来自材质/磨损/物理光的可信细节。**必须守住仙门极（威仪通透）与市井极（烟火温热）两极**。
- **氛围基调**：空灵悠远（大尺度留白云海）/ 清冷疏离（低饱和克制距离）/ 庄严静谧（殿宇秩序仪式感）/ 温润人间（市井暖光炊烟）
- **典型场景**：仙宫殿宇（唐宋殿堂形制，尺度锚定人如蝼蚁）/ 山门云海（御剑飞越超脱构图）/ 洞府丹室（蒲团丹炉烛火）/ 市井人间（青石板酒馆茶楼灯笼）/ 灵山胜境（演武场灵泉仙鹤）
- **材质语汇**（材质×状态，真实感来源）：棉麻（微皱肌理朴素）/ 丝绸云锦（暗纹流光华贵）/ 纱（透光纤维可见）/ 玉（次表面散射温润非死白）/ 金鎏金（局部剥落露底胎=千年包浆非新品）/ 木竹（木纹漆面冰裂）/ 石材（千年踩踏微凹但光洁=使用的庄严感）
- **光影**：自然光为主轴（晨雾/日出/日暮）；**体积光丁达尔（光柱浮尘可见边缘虚化）=仙气核心光语言**；阴影三层递进暗部永有信息；烛火丹炉火光（洞府静谧）；**灵气微光剂量严格克制**（来源化自发光体，非全景光照）；35mm 胶片微颗粒
- **色彩**：主色=玉白 `#F5F1E8`/素白（高明度低饱和暖白约60%）；辅助=黛青墨蓝 `#2B3540`+鎏金 `#C9A227`（约25%）；点缀=紫韵 `#7B6BA8`+朱红+玄青（10-15%）；市井极=土黄灰褐赭石暖米（略高饱和烟火气）；**玉白为底鎏金勾勒黛青压暗紫韵点睛**
- **反面清单**：现代痕迹（玻璃幕墙路灯塑料）/ 高饱和霓虹荧光 / 塑料感（硅胶果冻反光贴图）/ 西方哥特希腊 / 游戏插画厚涂 / 网红滤镜整容脸 / 破败废墟（仙侠的旧=包浆使用感非荒废）/ 强风衣袍吹旗（仙气=灵气悬浮非大风）/ 纯国画水墨（那是国画风）/ 特效堆砌魔幻金属铠甲
- **提示词锚定词**：`古风仙侠 / 仙气×写实 / 唐宋殿堂 / 玉白鎏金黛青 / 体积光丁达尔 / 材质包浆使用感 / 灵气微光克制 / 低饱和东方配色 / 仙门市井两极 / 电影胶片质感`
- **反向词**：`现代建筑 / 塑料感 / 高饱和霓虹 / 西方哥特 / 游戏厚涂 / 破败废墟 / 强风飘衣 / 特效堆砌 / 纯水墨国画`

> **核心铁律**：仙气靠克制与留白，不靠特效堆砌；「实」靠材质磨损/物理光/尺度锚定，不靠照片直抄。九成画面像"可住的真实世界"，一成画面给"非现实的超脱时刻"。

## 风格 3：现代都市（Modern Urban）

- **核心精神**：**在人工建成环境里"体面地活着"**——效率是秩序、精致是抵抗、疏离是保护壳、烟火气是短暂柔软；底层张力永远是"钢筋水泥的冷"与"一杯热咖啡的暖"的平衡。
- **氛围基调**：利落克制（线条干净动作干脆）/ 清醒疏离（人群中旁观感玻璃倒影）/ 冷冽带暖（建筑灰光暖雾气咖啡店雨夜灯箱）/ 松弛自洽（通勤高峰也带从容）
- **典型场景**：写字楼（玻璃幕墙大理石金属前台）/ 咖啡馆落地窗街角 / 高层公寓（落地窗夜景）/ 地铁通勤带（车厢扶手便利店自动门）/ 商业街夜景（霓虹招牌雨地反光车流灯轨）
- **材质语汇**（核心=**软硬冷暖反差并置**）：针织羊毛（柔软）/ 西装料羊毛呢（挺括垂坠）/ 牛仔（微旧磨白）/ 真皮（使用感旧化）/ 玻璃幕墙（通透反射雾气结露）/ 金属不锈钢（冷硬高光拉丝）/ 水泥清水混凝土（粗粝灰）/ 原木（温润家居感）/ 亚克力树脂（工业圆润）；**哑光与镜面共存、粗糙与光滑互衬**
- **光影**：自然光（清晨黄昏侧逆光斜窗光百叶格栅投影，阴天漫射=城市标准表情）；室内灯光（中性白为主暖黄为辅，办公均匀筒灯/公寓点光源温馨）；夜景霓虹（雨夜湿润路面彩色光斑倒影）；商业灯箱（局部冷白暖白高光）；**常用反差：冷调环境光+暖调人物光**
- **色彩**：主色=低饱和莫兰迪灰阶（雾霾蓝灰绿燕麦灰浅卡其灰粉鼠尾草绿）或黑白灰中性；辅助=暖驼米白暖灰藏青（体量层次）；点缀=小面积亮色（爱马仕橙克莱因蓝砖红荧光黄复古绿）；**配比约 7 成中性灰调+2 成莫兰迪+1 成点缀**；对比靠明度冷暖而非纯度，带"城市空气的灰"
- **反面清单**：古装汉服江湖武侠 / 奇幻魔法哥特暗黑 / **赛博朋克义体机械改装**（霓虹接近但义体化信息界面感属赛博不属现代都市）/ 乡村田园森林童话 / 蒸汽朋克废土末世 / 太空星际 / 巴洛克洛可可过度华丽 / 无人化极致极简超现实（必须有人与生活痕迹）
- **子类差异**：
  - **甜酷辣妹**：都市青春反叛面——色彩提亮（粉×黑白Y2K光泽），材质街头（PU皮格纹链条蝴蝶结），场景街角便利店夜店，光影霓虹迷离
  - **轻奢知性**：成熟精致面——低饱和高级灰+驼+细金点缀，材质羊毛呢真丝真皮，场景美术馆精品咖啡高端写字楼，光影柔和均衡
  - **职场 OL**：效率秩序面——黑灰白藏青驼制服感，材质挺括西装料衬衫利落包袋，场景写字楼会议室通勤，光影办公白亮均匀
  - **校园清新**：青春干净面——浅白浅蓝浅粉格纹，材质棉麻卫衣牛仔，场景校园书店操场，光影明亮晴澈
  - **都市夜行**：孤独浪漫面——夜景霓虹主光，深蓝黑+暖黄点缀，材质皮衣大衣玻璃反光，场景午夜便利店天桥车流，氛围最强
- **提示词锚定词**：`现代都市 / 体面地活着 / 玻璃幕墙 / 软硬冷暖材质反差 / 冷调环境+暖调人物 / 莫兰迪灰阶+点缀色 / 城市空气的灰 / 效率与疏离 / 烟火气`
- **反向词**：`古装 / 奇幻魔法 / 赛博义体 / 乡村田园 / 废土末世 / 过度华丽复古 / 无人化极简`

> **核心铁律**：都市必须有"人与生活痕迹"（烟火气不可剥离）；软硬冷暖材质反差是质感关键；冷调环境+暖调人物让主体"温和地跳出来"。

## 使用方式

1. 生成任何资产前：查本库 → 找到对应风格 → 先读「核心精神一句话」锚定气质
2. 再按 7 维取元素：氛围→典型场景→材质→光影→色彩（配合角色/场景语汇库取具体元素）
3. 风格段开头写「核心精神」锚定（如"高科技低生活——技术越灿烂生活越廉价"），再展开元素
4. 负面词必含「反面清单」关键词——防模型跑偏到"表层模仿"
5. 用户反馈（好/差）→ 更新本库（标注 ✅已验证）

## 风格 4：玄幻（Xuanhuan）

- **核心精神**：「以力证道，逆天改命——力量即奇观」。把「变强」放大成天地异象（境界突破/能量对冲/天劫雷罚/法相领域）；**与仙侠分野：玄幻拍"力量本身的演出"，仙侠拍"超脱的人"**。
- **氛围基调**：史诗磅礴（大陆位面尺度）/ 能量涌动（灵力蓄势爆发炽烈）/ 荒古苍莽（远古秘境原始压迫）/ 燃爆热血（力量崇拜逆袭爽感）

- **反面清单**：古风仙侠素净留白清冷仙气（水墨空灵不是玄幻）/ 武侠写实拳脚（无能量特效）/ 现代都市科技（霓虹义体全息）/ 西方奇幻（骑士哥特精灵魔法）/ 二次元卡通浮夸 / 市井日常烟火

## 风格 5：武侠（Wuxia）

- **核心精神**：「人在江湖，刀口舔血」——以血肉之躯行侠仗义，功夫是打出来的不是修出来的；刀是真刀、血是真血、剑招有套路有呼吸，**写实武打而非神通特效**。
- **氛围基调**：苍凉萧索（古道西风大漠孤烟）/ 紧绷肃杀（拔刀前对峙杀机四伏）/ 义气江湖（酒馆灯火快意恩仇）/ 粗粝人间（市井烟火刀客风尘）
- **典型场景**：客栈酒楼（刀客独坐酒碗暗器交错）/ 竹林（衣袂翻飞竹叶扫刀锋）/ 山道驿路（官道尘土驿站灯幌）/ 镖局（镖车武行铁门槛刀枪架）/ 庙会集市（人潮暗杀追逃）/ 雨夜长街（油纸伞对峙）
- **材质语汇**（写实磨损一切像用旧了）：粗麻棉布（洗旧褪色袖口磨破）/ 旧皮革（刀鞘马鞍皲裂油亮）/ 铁器（刀剑开刃寒光逼人刃口卷缺）/ 竹木（竹节油润木桌茶渍划痕）/ 石砖土墙（风化斑驳青苔）/ 粗陶酒坛 / 褪色酒旗镖旗
- **光影**：纯自然光+生活光源无特效——正午烈日干燥扬尘/ 黄昏逆光剪影/ 烛火油灯（客栈昏黄）/ 篝火（荒野营地）/ 雨夜灯笼（湿润地面反光）；**金属剑光仅来自自然光反射一瞬，无光晕无粒子**
- **色彩**：低饱和江湖色调——土黄赭石褐（大地沙尘）/ 墨色靛青灰（粗布劲装夜行衣）/ 旧木原色 / 朱红点缀（镖旗灯笼血迹）/ 苍白天际；如风吹日晒褪色老照片
