# 风格 DNA 库（style-dna）

> 供 movie-create-design-character / movie-create-design-scene / movie-create-drama-script 共用的**风格完整定义**（替代原 genre-keywords 单维度题材标签）。
> 每个风格 = 六维 DNA：**题材锚定 / 材质质感 / 运动表演 / 场景构图 / 分镜密度 / 声音** + **负面清单**。
> 对齐 ComfyUI-H3 的 `rules/styles/*.txt` 设计（每个风格独立文件式规则），但按我们的管线扩展。

---

## 风格 DNA 六维模板

```
【{风格名}】
- 题材锚定：{古装/奇幻/都市/科幻/悬疑...} → 提示词题材锚定句
- 材质质感：{画风 + 渲染质感 + 参考体系}
- 运动表演：{角色动作/运镜特征}
- 场景构图：{场景倾向 + 构图习惯}
- 分镜密度：{15s≈N镜/30s≈N镜/60s≈N镜}
- 声音：{环境声/BGM 倾向}
- 负面清单：{专属禁止项（补充共享 negative-block）}
```

## 风格库

### 1. 古装奇幻·仙侠（本剧「这宫斗剧本不对」）

```
- 题材锚定：古装+奇幻 → 国产{古装 奇幻}真人高清角色定妆棚拍；禁现代物品/现代建筑
- 材质质感：中国古典仙侠殿堂 + PBR 写实 + 玉白/鎏金/紫韵 + 参考《封神第一部》《英雄》《沙丘》
- 运动表演：仙侠衣袂但有重力感（非飘浮）；打斗用关键帧+运镜补偿；禁止顺滑 CG 漂浮
- 场景构图：仙家宫殿（高挑穹顶/盘龙柱/玉石地面）；竖屏 9:16 以中近景/特写为主
- 分镜密度：15s≈4镜、30s≈5-6镜、60s≈7-9镜；每镜一个情绪/信息单元
- 声音：仙宫环境（檀香/风铃/灵气嗡鸣）；BGM 古风管弦
- 负面清单：现代物品、粗粝石砌庙宇感、西方哥特、塑料 CG
```

### 2. 都市·职场

```

- 负面清单：古装元素、仙侠特效、粗颗粒胶片感（视风格定）
```

## 使用规则

1. **题材锚定句**：从「题材锚定」维度取词填入 `国产{题材词}真人高清角色定妆棚拍`。
2. **风格互斥反向词**：二次元/水墨等非写实风格，按「美术风格与反向词互斥」映射表切换反向词（写实→禁卡通；二次元→禁写实），风格 DNA 的「负面清单」补充专属项。
3. **分镜密度**：movie-create-drama-script 按本库密度生成镜头数（15s/30s/60s 参考）。
4. **声音**：分镜 JSON 的 sfx 参考本库声音维度。
5. **新风格**：按六维模板补充到本库，不散落各 skill。
