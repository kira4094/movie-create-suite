# 共享负面块（negative-block）

> 供 movie-create-design-character / movie-create-design-scene / movie-create-drama-script 等所有生图/生视频提示词引用的通用负面词库。
> 用法：提示词反向段 = 风格互斥反向词 + 本库通用负面块 + 任务特有负面。

## 基础负面块（按上下文组装）

```
默认只禁止无关文字、水印、logo、字幕条和漫画对话框；用户或剧情明确要求的招牌、UI、楼层号、协议编号、信件等文字必须逐字保留，不得加入冲突的“不要文字/字幕”规则。
```

## 分类扩展（按任务选用）

### 质量类
```
低画质、噪点、模糊、过度磨皮、塑料皮肤、分辨率低
```

### 一致性类
```
五官比例异常、模糊脸、面部崩坏、画面边缘裁切、半身、缺手脚、比例失调、多指
```

### 场景漂移类（按题材微调）
```
杂乱背景、多余人物、无关文字、乱码、错误拼写、水印、logo、外加字幕条、边框
古装/奇幻 → + 现代物品、现代建筑
都市/现代 → + 古装、宫廷、仙侠、古代建筑、现代古代混搭
科幻 → + 冷兵器、古建筑、农耕
```

### 细节失控类
```
服装结构不一致、覆盖关系错误、服装飘动、强风、衣摆飞扬、配饰晃动
```

### 安全与完整着装（正向约束）
```
完整着装、服装结构闭合、覆盖关系正确、服装与参考图一致
```

> 通用反向词不得自动加入“裸露”“私密部位”“裸体”“性器官”等直接性/解剖敏感词。需要表达安全边界时使用上面的正向视觉约束；具体平台审核仍以平台规则为准。

### 风格互斥类（由「美术风格与反向词互斥」映射表决定，不在此硬编码）
```
写实真人 → 卡通、插画、动漫、二次元、3D渲染、游戏CG、塑料感
二次元 → 写实、真人、照片、3D渲染、电影质感、皮克斯风
3D卡通 → 写实真人、平面插画、二次元赛璐璐、照片感
水墨国风 → 写实、油画、厚涂、3D渲染
```

## 用法规则

1. 反向段组装顺序：**风格互斥 → 按上下文选择的基础项 → 任务特有负面**
2. 任务特有负面（如情绪卡禁"中文标注"、多视图禁"下区出现头部"）追加在末尾
3. 正向风格词**绝不**出现在反向段（互斥铁律）
4. 组装前删除与剧情明确文字冲突的“不要文字/字幕”项；有剧情文字时保留原文并只抑制无关文字、乱码和错误拼写。
