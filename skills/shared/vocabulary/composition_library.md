# Composition Library｜构图词库

> 构图首先组织权力、距离、可见性和行动；美观是关系成立后的结果。

## 01. 尺度与权力

| 目标 | 构图方法 | 效果 |
|---|---|---|
| 压迫 | 低机位、巨物占上方、人物被挤边缘 | 系统/建筑压过个体 |
| 崇高 | 垂直透视、远高点、人物面对不可达之物 | 敬畏与渺小 |
| 孤立 | 大面积负空间、远景单人、稀少声源 | 脱节、等待、失落 |
| 集体压力 | 重复模块、密集人流、同步动作 | 规训、劳动、仪式 |
| 亲密 | 近景手部、低景深、共享物件 | 关系、照护、秘密 |

## 02. 视线与遮挡

- **框景**：门、屏幕、窗、拱门框住人物，表示控制、审判或观看。
- **前景遮挡**：隔着设施、植物、人群或玻璃看人，制造窥视或被困。
- **引导线**：道路、管线、光束、建筑边缘指向冲突主体。
- **反射**：镜子、水面、屏幕把身份、记忆或现实分成两层。
- **断裂**：切掉一部分身体、建筑或文字，制造未完成、排除或媒介感。

## 03. 空间节奏

- 三层景深：前景提供处境，中景承载行动，远景说明世界规模。
- 重复与例外：先建立相同的门窗/人群/符号，再留一个不一致的细节作为叙事焦点。
- 负空间：不是空白装饰，而是用于等待、隔离、神圣、压抑或呼吸。
