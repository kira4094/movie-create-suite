# Character Library｜人物词库

> 人物不是装饰。即使不露脸，也应能读出身份、处境、欲望和一个具体行动。

## 01. 人物四层

| 层级 | 要回答的问题 |
|---|---|
| 身份 | 他在这里做什么？劳动者、访客、照护者、权力者、局外人？ |
| 处境 | 他被什么资源、规则、身体状态或关系限制？ |
| 欲望 | 他想得到、守住、逃离、修复或证明什么？ |
| 行动 | 此刻具体在做什么？等待、维修、拒绝、观察、藏匿、分享？ |

## 02. 可视化线索

- 服装：功能、维护、阶层、制服、个人改造，不只追求“好看”。
- 身体：疲劳、姿势、伤痕、距离、手部动作和与空间的比例。
- 随身物：工具、票据、书、药物、旧照片、钥匙、容器，均应与行动有关。
- 视线：直视、回避、向上、看屏幕、看他人，决定人物是否拥有主体性。

## 03. 反抗/转折的最小单位

一只没有放下的手、一个被修补的物件、一次不看广告的转身、一个被保留的记忆、一次共享资源的动作，都可以构成足够小却可读的叙事变化。

## 04. 避免

- “酷的人物”但没有身份、动作和环境关系。
- 所有人脸、年龄、身体与服装同质化。
- 用悲伤表情代替真实的处境和选择。
