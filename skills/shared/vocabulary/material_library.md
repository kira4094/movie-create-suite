# Material Library｜材质词库

> 材质不是名词清单。每次描述至少写出：**材质 + 状态 + 作用/位置**，并让它说明时间、使用、环境压力或阶层。

## 01. 状态词

| 状态 | 可用词 | 叙事作用 |
|---|---|---|
| 全新/受控 | 抛光、无缝、校准、模压、镜面、精密 | 企业、奢侈、制度、未来承诺 |
| 日常使用 | 指纹、磨边、褪色、松动、压痕、贴纸残胶 | 生活、劳动、亲密、真实尺度 |
| 维修/拼接 | 焊点、补丁、替换件、胶带、外露线缆、缝补 | 匮乏、韧性、DIY、临时生存 |
| 衰败/污染 | 锈蚀、剥落、裂纹、霉斑、积尘、渗水、油污 | 时间、失序、忽视、环境代价 |

## 02. 材料组

### 金属

- 钢、铸铁：结构、劳动、工业重量；可加“焊接、锈蚀、雨水”。
- 铝、铬、不锈钢：轻量、消费现代性、医疗或无菌控制；可加“划痕、冷凝、指纹”。
- 铜、黄铜、青铜：时间、工艺、仪式或旧技术；可加“氧化、暗沉、铆钉”。

### 矿物与建筑

- 混凝土：制度、公共性、粗粝尺度；可加“模板纹、开裂、积水”。
- 石材、砖：历史、纪念性、地域；可加“风化、潮气、苔藓”。
- 玻璃、镜面：可见性、隔离、身份分裂；可加“雾气、反射、裂纹、污渍”。

### 人造材料

- 塑料、亚克力、树脂：消费、便利、廉价未来或玩具感；说明“发黄、磨砂、透明、注塑缝”。
- 橡胶、泡沫、合成纤维：运动、防护、医疗、临时性；说明“压缩、龟裂、潮湿”。
- 屏幕与电子：信息、监控、记忆；说明“扫描线、烧屏、指纹、线缆、故障像素”。

### 有机与手工材料

- 木、竹、藤：生长、手工、温度；说明“木纹、旧漆、榫卯、裂缝”。
- 纸、书、织物：记忆、知识、日常；说明“褶皱、毛边、墨迹、补丁、起球”。
- 皮革、蜡、骨、植物：身体、仪式、自然；说明“鞣制、蜡泪、干枯、潮湿”。

## 03. 提示词公式

`[状态] 的 [材质] [物件]，位于 [空间]，显示 [使用/环境痕迹]。`

例：`雨水浸湿、带焊点的锈钢管道横跨狭窄巷道，线缆以胶带临时固定。`

## 04. 避免

- 不要只写“金属感”或“高级材质”。
- 不要让所有物件同样新、同样旧、同样干净。
- 材质状态要和人物阶层、空间维护程度及世界观一致。
