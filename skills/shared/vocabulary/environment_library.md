# Environment Library｜环境与空间词库

> 环境必须是一个有历史、有维护方式、有权力分配的系统，而非背景布。

## 环境四问

1. 这个地方为谁设计？谁被排除？
2. 它靠什么能源、劳动和维护维持？
3. 时间、天气、污染或使用在这里留下了什么？
4. 人在此处能自由行动、被迫等待，还是被监控？

## 空间类型

- **基础设施**：车站、管线、堤坝、机房、网络节点；强调服务关系与维护者。
- **公共机构**：学校、医院、法院、展馆、避难所；强调规则、排队、可见性。
- **居住空间**：厨房、卧室、走廊、屋顶；强调习惯、照护、阶层与私密物。
- **商业空间**：商场、橱窗、广告墙、仓库；强调消费、流量、欲望管理。
- **边缘空间**：后巷、地下室、临时营地、空楼；强调非正式生存和被忽略的人。
- **自然/半自然**：农地、湿地、沙漠、森林；强调气候、季节、资源与人类干预。

## 生成公式

`[空间类型] + [维护/损耗痕迹] + [资源或规则] + [人物能否行动的限制]。`
