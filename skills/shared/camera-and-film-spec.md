# 电影相机与胶片规格库（camera-and-film-spec）

> 本文档是 movie-* skill 系列的**成像质感参考库**，供场景卡/角色卡/视频提示词引用。
> 目的：把「电影级质感」这种抽象词转化为**模型认得的精确型号描述**（ARRI/RED/胶片尺寸）——模型不认"电影级"，但认"ARRI Alexa 65 级宽容度 + 35mm 胶片颗粒"。
> 与 cinematography-handbook.md 分工：handbook 管**运镜**（镜头怎么动），本文档管**成像**（画面是什么质感）。

---

| 机型 | 画幅 | 关键画质特征 | 提示词用法 |
|------|------|------------|-----------|
| ARRI Alexa 65 | 65mm 大画幅 | 极高宽容度（14+ 档）、色彩科学自然、暗部干净无噪、动态范围电影级 | `ARRI Alexa 65 级宽容度与色彩科学` |
| ARRI Alexa Mini LF | 全画幅 LF | 色彩自然、肤色还原好、轻便机位灵活 | `ARRI Alexa 级色彩科学` |

| Sony Venice / Venice 2 | 全画幅 | 双原生 ISO、暗部极净、色彩饱和、电影感强 | `Sony Venice 级暗部与色彩` |

**提示词规范**：写「XX 级」而非纯型号（模型可能不认识型号名，但"级"传达质感层级）。示例：
- `ARRI Alexa 65 级电影质感，14 档宽容度，暗部干净无噪`
- `RED 8K 级锐度，细节丰富，微表面材质清晰`

| 类型 | 特征 | 提示词用法 |
|------|------|-----------|
| 变形宽银幕（Anamorphic） | 横向拉伸、椭圆形焦外光斑、水平拉丝炫光 | `变形宽银幕镜头，椭圆形焦外光斑` |

| 广角（24-35mm） | 空间透视夸张、近大远小 | `28mm 广角透视纵深` |

## 五、提示词组装规范（核心）

**「电影级质感」的标准写法 = 相机级 + 胶片规格 + 镜头 + 光学的组合**：

```
[相机级] + [胶片规格/颗粒] + [镜头/景深] + [宽容度/色彩]
示例：ARRI Alexa 级色彩科学，35mm 胶片微颗粒，f/2.8 大光圈浅景深，14 档宽容度暗部干净
```

**按用途选型**：

| 场景类型 | 推荐组合 |
|---------|---------|
| 仙宫/史诗大场面（紫极仙宫） | IMAX 65mm 级宏大 + 变形宽银幕 + 浅景深 |
| 仙侠唯美（云巅/花海） | ARRI Alexa 级色彩 + 35mm 颗粒 + 长焦压缩 |
| 悬疑/压迫（天雷压顶） | Sony Venice 级暗部 + 16mm 颗粒 + 广角透视 |
| 闪回/回忆（前世） | Super 8 胶片怀旧 + 高对比褪色 |
| 战斗/动作 | RED 8K 锐度 + 手持感 + 快切 |

## 六、负面排除（配合使用）

- 禁止：手机感/锐化过度/数码噪点/电子果冻效应/游戏 CG 感/3D 渲染贴图感
- 仙侠题材附加：禁止西方胶片色调（青橙好莱坞调可少量），优先东方色彩审美
